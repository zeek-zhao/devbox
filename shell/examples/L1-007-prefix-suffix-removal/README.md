# L1-007-prefix-suffix-removal

<!-- coverage: pending -->

## 考点
对应 KP-SH-L1-07：前缀使用 `#`/`##`、后缀使用 `%`/`%%` 移除模式匹配。
看到单符号留下最短匹配后的内容、双符号移除最长匹配，即为掌握。

## 易错点
单个符号只移除最短匹配，双符号移除最长匹配；匹配范围取决于模式。
先判断模式覆盖的前缀或后缀，再选择单符号或双符号，避免多删文件名内容。

## 延伸
把参数展开用于拆分归档文件名，分别取得扩展名和主体。
测试没有匹配项、多个点号及隐藏文件名，确认模式边界符合预期。
