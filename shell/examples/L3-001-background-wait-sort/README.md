# L3-001-background-wait-sort


## 考点
对应 KP-SH-L3-01：并发启动后台任务，逐一 `wait` 后再稳定输出结果。
即使任务完成顺序不同，最终结果仍按字母排序且多次运行逐行一致，就说明掌握了该 KP。

## 易错点
直接打印后台任务输出会受调度顺序影响，因为任务完成先后不固定。
先将结果分别收集、等待所有 PID 结束，再按稳定键排序后输出。

## 延伸
把固定结果文件改为带任务编号的巡检结果，按编号汇总并检查失败状态。
进一步练习限制并发数，并确保每个后台任务的退出状态都被检查。
