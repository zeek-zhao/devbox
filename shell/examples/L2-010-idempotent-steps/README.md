# L2-010-idempotent-steps


## 考点
对应 KP-SH-L2-10：重复执行配置步骤应到达同一目标状态。
连续运行两次后内容相同且目标行只出现一次，说明重跑不会重复追加或改变状态。

## 易错点
无条件追加或重复创建会使每次运行改变状态，因为脚本把“执行过”误当成目标状态。
先检查目标内容，再用临时文件和重命名更新，保证重复执行结果稳定。

## 延伸
把部署配置写成“声明目标状态、检查当前状态、必要时修复”的步骤。
为重跑验证扩展内容、权限和服务状态等可观察断言。
