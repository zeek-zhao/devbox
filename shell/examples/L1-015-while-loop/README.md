## 考点
对应 KP-SH-L1-15：用条件命令控制 `while` 循环继续或结束。
看到循环恰好输出两轮且最终计数达到边界 2，说明更新与终止条件正确。

## 易错点
若循环条件成立时不更新条件变量，循环可能永不结束。
在循环体更新计数，并验证结束边界和最终值。

## 延伸
将有限循环用于有明确次数上限的轮询或重试。
为重试增加上限判断和最终失败处理，确保流程有界。
