# L2-011-failure-diagnostics


## 考点
对应 KP-SH-L2-11：失败步骤应报告具体操作并保留非零状态。
读取缺失配置时 stderr 指出 `read-config`、脚本非零退出且 stdout 没有成功标记，说明失败路径可诊断。

## 易错点
仅输出通用失败或吞掉原退出状态会误报成功，也无法定位哪个操作失败。
保留失败分支并报告具体操作；不要把失败转换成成功退出或成功输出。

## 延伸
为部署中的关键命令增加包含操作上下文的错误信息，同时保留失败退出状态。
区分用户输入错误、依赖不可用和目标状态异常，以便自动化调用方处理。
