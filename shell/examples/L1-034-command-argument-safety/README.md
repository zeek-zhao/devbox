# L1-034-command-argument-safety


## 考点
对应 KP-SH-L1-34：用 Bash 数组分别保存命令参数，并用 `"${args[@]}"` 保留参数边界。
含空格与分号的数据仍是单个字面参数、没有额外命令执行，说明掌握安全传参。

## 易错点
`eval` 会再次解析数据中的 Shell 元字符，可能执行意外命令；用数组保存命令及参数。
始终以 `"${args[@]}"` 展开参数数组，避免字符串拼接造成分词和元字符解释。

## 延伸
将配置文件解析出的参数保存为数组，再交给外部命令执行而非拼接命令字符串。
为命令包装器添加参数校验，同时保留每个参数原有的空格与特殊字符。
