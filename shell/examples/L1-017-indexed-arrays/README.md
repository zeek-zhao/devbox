# L1-017-indexed-arrays


## 考点
对应 KP-SH-L1-17：创建 Bash 索引数组并按下标和元素列表读取。
看到下标 1 取出第二项、总数为 2，且含空格与 `*` 的元素原样传递，说明掌握了数组展开。

## 易错点
未引用的数组展开会拆分元素并展开 glob，导致参数内容或数量变化。
逐元素传参使用 `"${items[@]}"`，并引用数组下标和长度展开。

## 延伸
用数组维护待巡检项目，再将每个元素作为独立参数传递给函数。
练习动态追加元素和按下标更新元素。
