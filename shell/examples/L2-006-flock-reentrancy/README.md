# L2-006-flock-reentrancy


## 考点
对应 KP-SH-L2-06：用 `flock` 限制同一任务同时进入临界区。
竞争者在首个进程持锁时报告 busy，首个进程释放后再次获取成功，说明文件锁协调了并发进程。

## 易错点
用固定标志文件代替锁不能原子协调并发进程，两个进程可能同时判断标志不存在。
让竞争者对同一锁文件打开文件描述符并尝试 `flock -n`，用就绪和释放 FIFO 握手。

## 延伸
将文件锁用于毕业项目中重复部署、巡检或定时任务的互斥保护。
为锁定失败规定明确策略，并验证持锁进程退出后其他调用能够继续。
