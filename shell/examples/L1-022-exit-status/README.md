# L1-022-exit-status


## 考点
对应 KP-SH-L1-22：从命令退出状态区分成功与失败，并及时处理 `$?`。
看到 `false` 的状态非零且 `true` 走成功分支，说明能正确判断命令结果。

## 易错点
后续命令会覆盖 `$?`，延迟读取可能得到另一个命令的状态。
在 `if command; then ... else ... fi` 中直接分支更清楚，也不易误读。

## 延伸
为会失败的检查命令添加 `if` 分支，并明确处理成功与失败两种路径。
练习将失败状态传递给调用方，而不是意外用后续命令覆盖它。
