# L2-004-bats-fixtures


## 考点
对应 KP-SH-L2-04：Bats 的 `setup` 和 `teardown` 为每条测试建立并清理 fixture。
第一条测试修改状态后，第二条仍读到初始内容且测试后目录为空，说明隔离和清理有效。

## 易错点
测试共享可变文件会产生顺序依赖，前一条测试的修改可能污染后一条。
由钩子为每次测试建立和清除夹具，不要依赖测试执行顺序或手动复位共享状态。

## 延伸
把 fixture 扩展为隔离的配置文件、临时工作区或模拟部署状态。
在毕业项目测试中检查成功与失败路径结束后都不会留下临时内容。
