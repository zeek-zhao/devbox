# L3-004-sha256-integrity

<!-- coverage: pending -->

## 考点
对应 KP-SH-L3-04：提取 `sha256sum` 摘要并与已知内容摘要比较。
原始文件校验通过、改动一个字节后比较不匹配，就说明掌握了该 KP。

## 易错点
只打印 `sha256sum` 的显示文本而不检查比较结果，会漏报文件变化。
提取摘要字段并显式比较；不匹配时应进入非零失败分支，而非只展示哈希。

## 延伸
将固定摘要校验应用到本地产物清单，并在汇总中指出不匹配的文件名。
练习用受信任的摘要清单验证多个文件，同时区分缺失文件与内容变化。
