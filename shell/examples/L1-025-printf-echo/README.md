# L1-025-printf-echo


## 考点
对应 KP-SH-L1-25：使用格式明确的 `printf` 输出字面量、反斜线和变量值。
看到 `-n` 被原样输出、反斜线不被意外解释且插值结果稳定，即掌握此点。

## 易错点
`echo` 对 `-n` 和反斜线的处理存在实现差异，导致输出可能改变。
需要稳定输出或插值时使用带明确格式串的 `printf`，避免依赖 `echo` 行为。

## 延伸
练习用 `%s` 输出用户提供的任意文本，避免文本被当作格式串解释。
为结构化日志规定固定字段、分隔符和换行，再用 `printf` 稳定生成。
