## 考点
对应 KP-SH-L1-28：用 `getopts` 解析无值选项和带值选项，并拒绝非法选项。
看到 `-a` 被启用、`-b` 保留完整参数值，且缺少 `-b` 的值被拒绝，说明掌握短选项解析。

## 易错点
选项串中的 `b:` 表示 `-b` 必须带值；漏写冒号会让后续参数被错位解析。
声明带值选项并处理缺值状态，避免把选项名误当成参数值。

## 延伸
为命令行添加互斥选项和必填参数检查，并在错误时输出统一用法说明。
把解析结果传给后续操作前，验证选项组合是否满足命令的约束。
