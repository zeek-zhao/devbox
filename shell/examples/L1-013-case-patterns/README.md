# L1-013-case-patterns


## 考点
对应 KP-SH-L1-13：用 `case` 按 Shell 模式分派输入。
看到 `start` 命中对应模式、未知输入进入 `*` 并返回非零，说明掌握了分支和兜底。

## 易错点
`case` 使用通配模式而非正则表达式；未知输入若无 `*` 可能没有明确处理。
保留兜底分支并显式返回失败状态，调用方再处理该状态。

## 延伸
将 `case` 用于子命令路由，并分别校验每个子命令的参数。
练习用 `|` 在一个模式分支中列出多个可接受选项。
