## 考点
对应 KP-SH-L1-19：区分 `"${items[@]}"` 的逐元素展开与 `"${items[*]}"` 的合并展开。
看到前者传出两个参数、后者传出一个含空格的参数，就说明掌握了边界差异。

## 易错点
误用 `"${items[*]}"` 会把元素合并并丢失边界。
逐个传递数组元素时用 `"${items[@]}"`，并始终加双引号。

## 延伸
将数组展开传给函数或外部命令，观察参数个数与含空格元素的完整性。
再尝试不同的 `IFS`，确认 `[*]` 的合并分隔符会随之变化。
