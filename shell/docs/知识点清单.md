# Shell 知识点清单

## 1. 怎么用这份清单

每个 KP 编号对应一个独立用例；验收以表中的可观察现象为准。L1 聚焦 Bash 语言与常用命令行为，L2 聚焦脚本工程、测试和质量门禁，L3 聚焦数据规模、并发与专题工具。Shell 的字符串展开、词分割、退出状态和进程模型是贯穿各级的核心，不按其他语言的语法分类。

| 内容 | 为什么不覆盖 |
|---|---|
| 需要管理员权限的系统管理命令 | 用例运行身份无特权，无法稳定创建或修改系统级资源；课程聚焦普通用户可重复执行的脚本行为。 |
| 访问外部网络服务 | 容器无外网，依赖远端可用性的断言无法运行；用固定本地输入验证解析与错误处理。 |
| 容器镜像中未提供的第三方命令行工具 | 环境无法保证安装或版本一致；只选镜像已确认提供的 Bash、ShellCheck、Bats 和文本处理工具。 |
| 等待真实用户输入的交互流程 | 自动用例没有可控终端输入，可能永久阻塞；仅测试通过参数或标准输入提供数据的非交互路径。 |
| 依赖机器时钟、随机调度或当前绝对路径的输出 | 这些结果不能逐次稳定比较；用固定输入并在并发场景收集后排序。 |
