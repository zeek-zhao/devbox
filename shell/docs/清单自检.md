### 探针 1：KP-SH-L1-03

<!-- probe:lang=shell -->

```bash
#!/usr/bin/env bash
set -euo pipefail
value='two words'
show_args() {
  printf 'argc=%s\n' "$#"
  printf '<%s>\n' "$@"
}
show_args $value
show_args "$value"
```

**实测输出**

```text
argc=2
<two>
<words>
argc=1
<two words>
```

### 探针 2：KP-SH-L2-04

<!-- probe:lang=shell -->

```bash
#!/usr/bin/env bash
set -euo pipefail
cat > check.bats <<'EOF'
setup() { value=ready; }
teardown() { unset value; }
@test "run captures output and status" {
  run printf '%s' "$value"
  [ "$status" -eq 0 ]
  [ "$output" = ready ]
}
EOF
bats --tap check.bats
```

**实测输出**

```text
1..1
ok 1 run captures output and status
```

### 探针 3：KP-SH-L3-01

<!-- probe:lang=shell -->

```bash
#!/usr/bin/env bash
set -euo pipefail
work=$(mktemp -d)
trap 'rm -rf "$work"' EXIT
(printf 'beta\n' > "$work/b") &
p1=$!
(printf 'alpha\n' > "$work/a") &
p2=$!
wait "$p1"
wait "$p2"
sort "$work"/*
```

**实测输出**

```text
alpha
beta
```
