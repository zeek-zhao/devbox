### 探针 4：KP-PY-L1-32

<!-- probe:lang=python -->

```python
from functools import lru_cache


@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)


print(fib(20))
info = fib.cache_info()
print(f"hits>0: {info.hits > 0}")
print(f"misses: {info.misses}")

try:
    @lru_cache(maxsize=None)
    def count(items):
        return len(items)

    count([1, 2])
except TypeError as exc:
    print(f"unhashable: {type(exc).__name__}")
```

**实测输出**

```text
6765
hits>0: True
misses: 21
unhashable: TypeError
```
