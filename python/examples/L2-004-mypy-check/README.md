## 考点
对应 KP-PY-L2-04：固定运行 mypy，并把类型错误转成可观察的门禁结果。
正确调用通过、错误调用被拒绝且 runner 仍成功，说明门禁传播与负例断言有效。

## 易错点
只添加注解而不运行检查器，调用端的不兼容类型仍会漏过。
固定检查命令并显式处理预期负例；正常检查失败时必须保留非零状态。

## 延伸
将同一 mypy 命令接入 CI，对整个项目约定范围执行类型门禁。
逐步启用更严格的检查选项，并为报告中的错误位置添加类型信息。
