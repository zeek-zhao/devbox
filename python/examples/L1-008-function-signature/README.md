# L1-008-function-signature

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-08：用 `/` 限制仅位置参数，以 `*` 分隔关键字专用参数，并收集额外参数。
有效调用将额外位置参数放入 tuple、额外关键字参数放入 dict；把仅位置参数按名称传入会被拒绝。
观察两种收集结果及负例结论，即可确认签名约束生效。

## 易错点
忘记 `/` 或 `*` 会让接口接受非预期调用方式；用显式签名约束公共函数并用错误调用验证限制。
仅位置参数和关键字专用参数的边界由函数签名定义，不能依赖调用者自律。
对外接口显式标注边界，并捕获预期的 `TypeError` 来验证无效调用被拒绝。

## 延伸
为 CLI 命令处理器定义稳定签名，区分命令名、可变位置参数和关键字选项。
继续使用 `inspect.signature` 检查公共函数接口，避免意外扩大调用方式。
