# L1-021-inheritance-super


## 考点
对应 KP-PY-L1-21：通过覆盖方法和 `super()` 扩展继承行为。
初始化记录与渲染顺序都符合方法解析顺序，说明子类保留并协作扩展了父类行为。

## 易错点
直接写死父类名会绕过协作式多重继承中的下一个方法。
使用 `super()` 并保持方法签名兼容，才能让整个 MRO 链继续执行。

## 延伸
可以添加新的混入类并调整继承顺序，观察 MRO 如何改变协作调用顺序。
在真实报表格式处理器中，用相同模式分层组合通用与特定行为。
