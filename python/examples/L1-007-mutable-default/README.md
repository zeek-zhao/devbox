# L1-007-mutable-default


## 考点
对应 KP-PY-L1-07：验证默认参数表达式只在函数定义时求值一次。
连续调用使用可变默认列表时，长度依次增长；使用 `None` 哨兵时，两次独立调用都从空列表开始。
观察两组长度，即可识别共享默认对象并掌握安全写法。

## 易错点
可变默认值会跨调用保留修改，因为默认表达式只求值一次；默认用 `None` 作哨兵并在函数体新建容器。
即使函数调用看似彼此独立，默认列表仍然是同一个对象。
不要用共享的可变默认值保存请求状态；在默认值为 `None` 时创建新容器。

## 延伸
用安全写法累积筛选结果，验证多个请求之间不会意外共享状态。
继续阅读函数对象的 `__defaults__`，观察默认值与函数定义之间的关系。
