# L1-020-eq-hash

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-20：为不可变相等状态配套实现 `__eq__` 与 `__hash__`。
相等对象的哈希契约成立、set 去重且可用等价键查询 dict，说明键行为正确。

## 易错点
相等对象若哈希不同，dict 和 set 会按不同位置处理它们，查找与去重随之失效。
相等状态可变时不要提供稳定哈希；应选用不可变键，并且不要依赖哈希数值本身。

## 延伸
为报表维度构造不可变键，并在 dict 与 set 中验证去重和查找行为。
为定义了相等比较的可变记录验证其不可哈希，避免作为字典键后状态漂移。
