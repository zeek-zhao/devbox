# L1-002-mutability-identity


## 考点
对应 KP-PY-L1-02：区分身份、值相等与可变性。
两个独立列表应满足 `==` 为真且 `is` 为假；元组所含列表仍可原地追加。
只对 `None` 这样的单例使用 `is`，即可观察到这些语义差异。

## 易错点
用 `is` 比较值会受对象缓存影响；用 `==` 判断单例身份也不严谨，应只对 `None` 等单例用 `is`。
值相等不代表是同一个对象，数值对象的身份也不适合作为业务判据。
比较普通值用 `==`，检查单例用 `is`；需要修改时确认对象本身可变。

## 延伸
把独立列表用于记录与查询结果，观察修改一个列表是否影响另一个列表。
在不可变容器中保存可变成员，继续区分容器自身不可变和成员可变。
