# L2-007-argparse-cli

<!-- coverage: pending -->

## 考点
对应 KP-PY-L2-07：由 `argparse` 统一处理位置参数、类型转换、帮助和错误分支。
有效参数产生预期值、缺参被拒绝而帮助成功，说明解析约束工作正常。

## 易错点
手工拆 `sys.argv` 容易遗漏缺参、未知选项与帮助分支，类型转换也容易不一致。
声明位置参数和选项约束，让解析器统一处理错误与帮助输出。

## 延伸
为清洗和报表子命令添加独立参数，并用解析器的子命令能力组织入口。
为路径、枚举值等参数声明类型或自定义校验，避免业务逻辑重复解析。

## 复现
TAG=latest scripts/run-example.sh python L2-007-argparse-cli
