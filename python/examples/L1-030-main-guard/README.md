# L1-030-main-guard

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-30：通过主入口守卫区分模块导入与脚本直接执行。
导入时没有入口输出而直接执行时运行 `main()`，说明导入不会意外启动 CLI。

## 易错点
导入阶段执行 CLI 会让测试和复用产生副作用，且调用方无法只复用模块定义。
把启动逻辑放进 `main()`，只在 `if __name__ == "__main__"` 守卫内调用。

## 延伸
可将命令行解析保留在入口函数，把可复用业务逻辑放在独立函数或模块中。
在测试中分别导入模块和调用入口，检查副作用边界。
