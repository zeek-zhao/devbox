# L1-018-slots

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-18：用 `__slots__` 限制实例属性，并检查子类继承中的声明。
不引入字典的子类拒绝未声明属性，而重新引入 `__dict__` 的子类可以添加任意属性，即说明掌握。

## 易错点
子类重新声明 `__dict__` 会恢复任意属性存储，使预期的 slots 限制失效。
逐层检查继承声明；slots 只用于对象布局和属性约束，不是安全边界。

## 延伸
为大量轻量报表行比较仅声明 slots 的子类与带字典子类的行为。
将外部输入校验放在模型接口中，不依靠 slots 阻止不可信数据。
