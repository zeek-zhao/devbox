# L1-005-index-slice

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-05：运用负索引、半开切片和步长切片提取序列片段。
固定字符串的区间切片不包含终点，反向切片可逆序；越界切片为空而单项越界会报错。
这些观察结果都匹配预期，即可说明掌握了索引和切片边界。

## 易错点
混淆切片终点包含关系会多取一项；切片终点不包含，单项索引才会因越界报错。
切片会在边界处截断，不会像单项索引那样因越界抛出 `IndexError`。
需要固定数量的元素时核对半开区间端点；访问单项时先保证索引有效。

## 延伸
将半开切片用于分页和字段区间提取，并验证相邻页面不重叠也不遗漏。
进一步练习带步长切片处理固定格式字符串或反向遍历序列。
