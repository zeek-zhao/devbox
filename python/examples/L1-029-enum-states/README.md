# L1-029-enum-states

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-29：用枚举表达有限状态，并分别观察成员身份、名称和值。
同一成员身份比较成功、原始字符串不等于成员，且名称和值各自明确输出，说明掌握枚举边界。

## 易错点
把字符串直接与枚举成员比较会得到不匹配；名称和值也不是可互换的表示。
在输入边界集中按枚举值转换，并把非法值转换成明确的拒绝结果。

## 延伸
可以为 CLI 任务状态增加合法转换表，阻止状态跳转到未定义状态。
在解析层集中把外部文本转换为枚举，业务逻辑只处理枚举成员。
