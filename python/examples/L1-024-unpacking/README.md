# L1-024-unpacking


## 考点
对应 KP-PY-L1-24：用位置解包和星号目标接收可变长度序列的剩余部分。
首尾字段正确提取且中间字段完整保留，说明解包不依赖输入恰好为固定长度。

## 易错点
把输入直接固定解包到固定数量变量，在字段数变化时会抛出 `ValueError`。
用星号目标接收可变部分；若业务要求固定长度，则先显式验证长度。

## 延伸
可以把记录行拆分为首字段、可变中间字段和尾部校验字段。
再用映射解包组合默认配置与覆盖项，并明确重复键的覆盖规则。

## 复现
TAG=latest scripts/run-example.sh python L1-024-unpacking
