# L1-010-closure-late-binding

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-10：观察闭包延迟查找循环变量，并用默认参数固定创建时的值。
循环创建的普通 lambda 调用时都读到最后一个值；带默认参数的版本分别保留各自值。
观察两组列表的差异，即可确认理解闭包的 late binding。

## 易错点
闭包捕获的是变量绑定而非创建时的值，调用时循环已结束会全取最后值；用默认参数或工厂函数固定值。
循环内创建函数不会自动复制循环变量当前值。
需要延迟执行时用默认参数保存当次值，或通过工厂函数为每次迭代创建独立作用域。

## 延伸
将列转换规则延迟到报表执行时调用，比较共享循环变量和固定默认参数的结果。
继续练习工厂函数与回调注册，检查函数创建和调用的时间差异。
