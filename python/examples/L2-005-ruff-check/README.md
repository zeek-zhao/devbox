# L2-005-ruff-check


## 考点
对应 KP-PY-L2-05：在完整用例目录运行 `ruff check`，并验证违规代码会被拒绝。
目录范围检查通过、已知违规返回失败，说明 lint 门禁既覆盖范围也传播错误。

## 易错点
只检查改动文件可能漏掉新增目录或配置覆盖，忽略返回码还会吞掉真实告警。
在仓库约定范围执行同一命令，检查失败时明确返回非零。

## 延伸
把项目根目录的 lint 命令固定到 CI，并对新增模块保持相同检查范围。
结合规则配置选择常见缺陷与风格规则，定期评估误报和遗漏。

## 复现
TAG=latest scripts/run-example.sh python L2-005-ruff-check
