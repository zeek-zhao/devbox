# L1-012-comprehensions

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-12：区分立即执行的列表推导式与按需执行的生成器表达式。
生成器创建时计算记录仍为空，调用 `next()` 才记录一项，完整消费后才记录全部输入，即说明掌握。

## 易错点
生成器表达式只能逐项消费，迭代耗尽后不能像列表一样重复遍历。
需要多次使用时显式物化为 `list`；只需逐项处理时保留生成器以节省内存。

## 延伸
将生成器用于逐条筛选报表字段，并比较消费前后的处理记录。
需要重用结果时，在明确的消费点将生成器转成列表。
