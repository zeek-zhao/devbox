# L1-006-functions-return


## 考点
对应 KP-PY-L1-06：通过函数参数接收输入，并用返回值传递计算结果。
调用计算函数后，调用方能将结果继续赋给名称；只打印的函数调用结果则为 `None`。
观察输出与返回值各自的位置，即可确认理解两者职责不同。

## 易错点
把打印当作返回会让调用方拿到 `None`；用返回值传递计算结果，把输出留给 CLI 层。
`print()` 只负责展示，不会自动把展示内容交给调用方。
可复用的计算逻辑显式 `return`；由调用层决定是否以及如何打印。

## 延伸
将清洗和报表计算封装成返回结构化数据的函数，再由 CLI 层负责展示。
继续练习输入校验与异常处理，保持业务计算和终端输出相互独立。
