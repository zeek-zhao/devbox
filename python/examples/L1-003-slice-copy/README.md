# L1-003-slice-copy

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-03：比较列表切片的浅拷贝与 `copy.deepcopy` 的深拷贝。
修改浅拷贝的内层列表会同时改变原列表，而修改深拷贝的内层列表不会。
观察内外层结果的差异，说明理解了嵌套对象的共享关系。

## 易错点
只检查外层列表会误以为切片复制了所有层；用嵌套列表验证，并按所有权需求选择深拷贝。
切片只新建外层列表，内层成员仍然引用原来的对象。
需要隔离嵌套状态时使用深拷贝，并根据数据所有权确认复制成本与语义。

## 延伸
用报表数据创建独立快照，比较浅拷贝和深拷贝在嵌套字段上的影响。
继续学习自定义对象的复制协议，以及何时应避免复制并改用不可变数据。
