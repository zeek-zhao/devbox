# L1-011-decorators-wraps

<!-- coverage: pending -->

## 考点
对应 KP-PY-L1-11：用带参数的装饰器包装函数并保留函数元信息。
输出中的函数名、文档字符串与原函数一致，且调用结果带有指定前缀，即说明掌握。

## 易错点
装饰器不使用 `wraps` 会让公开的函数名和文档变成包装函数自己的元信息。
在包装层使用 `@wraps(func)`，并透传参数及返回值，避免调用接口和元信息丢失。

## 延伸
把装饰器用于命令执行的审计钩子，记录命令名称与稳定的业务结果。
再测试带关键字参数的调用，确保包装层对原函数接口透明。
