# L1-017-class-attributes


## 考点
对应 KP-PY-L1-17：区分类属性共享状态与 `__init__` 中创建的实例状态。
一个对象更新实例列表不改变另一个对象的列表，而类列表的修改被两者观察，即说明掌握。

## 易错点
把可变类属性误当成每个对象的状态，会让不同记录之间发生意外串扰。
在 `__init__` 中给 `self` 赋独立列表；只有确实要共享时才使用可变类属性。

## 延伸
把类属性用于共享的记录类型配置，把每行报表数据放入各自实例属性。
为多个记录对象编写隔离性测试，确认修改一行不会改变另一行。
