# L1-014-generators-lazy


## 考点
对应 KP-PY-L1-14：生成器函数调用只创建生成器，`yield` 在消费时逐步推进计算。
创建后计数为 0、每次 `next()` 增加一次、消费完才显示全部副作用，即说明掌握。

## 易错点
把调用生成器函数当成已完成计算，会错过迭代期间才发生的副作用。
在消费点检查状态，并逐项推进生成器，不能只检查生成器对象已经创建。

## 延伸
用生成器分批解析大文件，并在每次消费后检查已处理记录数。
把过滤步骤串联成惰性流水线，确认未消费的记录不会触发解析。
