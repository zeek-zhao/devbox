# L1-001-name-object


## 考点
对应 KP-PY-L1-01：名称绑定对象，对象具有运行时类型。
先将名称绑定到整数、再绑定到字符串后，另一个名称仍指向原整数。
观察 `type()` 分别显示 `str` 与 `int`，即可确认理解重绑定不会改写旧对象。

## 易错点
把变量当成装有值的盒子会误以为赋值会修改原对象；名称实际是绑定，需区分重绑定与对象修改。
重新给名称赋值只改变该名称的绑定，不会修改其他名称仍引用的对象。
需要更新共享可变对象时要执行对象操作，而不是把重绑定误认为原地修改。

## 延伸
追踪 CLI 参数从字符串转换为整数等业务数据时，区分原始输入与新绑定。
继续观察多个名称引用同一可变对象时，原地修改与重新绑定的不同效果。
