# L2-001-package-imports


## 考点
对应 KP-PY-L2-01：用包边界、`__init__.py` 和相对导入组织模块。
直接运行包内文件被拒绝、从包根以 `python -m` 导入成功，说明掌握了启动方式。

## 易错点
直接运行带相对导入的文件会因没有父包而失败，脚本所在目录不是包上下文。
从包根使用 `python -m` 启动，并保持明确的包结构和入口。

## 延伸
将 CLI、清洗与报表分别放入包内模块，由单一模块入口组合调用。
练习从项目根运行包入口，避免依赖当前目录偶然影响导入结果。

## 复现
TAG=latest scripts/run-example.sh python L2-001-package-imports
