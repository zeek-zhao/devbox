# L3-005-counted-benchmark


## 考点
对应 KP-JV-L3-05：对查找算法预热、重复计时，并消费校验和。
线性查找访问 1000 次、二分查找不超过 10 次，两者校验和一致；只验操作数，不把耗时当性能门槛。

## 易错点
单次墙钟受 JIT、预热与调度扰动；不消费结果还可能让工作被优化掉。
重复采样并消费结果校验和，expected 只比较确定的计数与校验和，不比较时间。

## 延伸
将固定数组替换为词项查询数据，分别记录比较次数与结果校验和。
进一步比较不同数据分布，但把性能结论与正确性验收分开。
