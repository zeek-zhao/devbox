# L1-015-type-erasure


## 考点
对应 KP-JV-L1-15：不同泛型实参的列表在运行时共享同一擦除后的类。
输出展示运行时类相同，并以捕获的转换异常观察 raw type 污染读取点的后果。

## 易错点
读取泛型列表会抛转换异常，因为原始类型绕过编译期检查且读取点补入类型转换；消除 raw type，不能靠 getClass 还原元素类型。
保留参数化类型并避免 raw type；运行时类相同不能说明列表元素类型可恢复。

## 延伸
查看泛型方法的字节码签名与编译器生成的桥接方法。
研究类型令牌如何由调用方显式传递运行时类型信息。
