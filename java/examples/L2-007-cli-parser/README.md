## 考点
对应 KP-JV-L2-07：手写 String[] 参数解析需处理帮助、选项、缺值和数值范围。
看到合法 limit 输出固定两项、help 成功，未知选项/缺参/非数字/负数均非零拒绝，即掌握解析约束。

## 易错点
非法输入会被误接受或数组越界，因为直接取下个参数且未校验范围。
先检查参数存在，再显式解析并验证范围；错误写固定用法到 stderr 且不得返回成功。

## 延伸
为构建与查询子命令添加独立选项，并把语法校验与业务执行分开。
扩展为重复选项及互斥参数的解析，并为错误码建立稳定协议。
