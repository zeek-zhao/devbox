# L1-020-stream-pipeline


## 考点
对应 KP-JV-L1-20：filter/map 中间操作惰性执行，终止操作驱动流水线，流不能二次消费。
计数在终止操作前为零、collect 后为二，并观察复用同一流被拒绝，即可确认掌握。

## 易错点
流水线可能未运行或二次消费失败，因为中间操作惰性且流只能消费一次；执行终止操作，需要重跑时重新建流。
需要重复处理数据时从数据源重建流，不要再次操作已消费的流。

## 延伸
将文档过滤条件与词项转换组合为可测试的流水线。
比较 `collect` 与其他终止操作，并确认每条流水线只消费一次。
