# L1-014-generic-safety


## 考点
对应 KP-JV-L1-14：泛型约束列表元素类型，类型参数不因子类关系而协变。
编译探针显示错误元素添加与子类型列表赋给父类型列表均被拒绝，泛型读取仍返回对应类型。

## 易错点
子类型列表不能赋给父类型列表，因为后者允许写入其他 Number；使用适当通配符而非原始类型。
保留具体泛型参数；需要跨类型读取或写入时选合适的通配符，而非绕过检查。

## 延伸
为索引查询实现泛型方法，验证不同元素类型仍能安全返回元素。
继续学习有界类型参数及其对泛型 API 表达能力的影响。
