# L1-001-reference-values


## 考点
对应 KP-JV-L1-01：Java 按值传递，对象参数传递的是引用值的副本。
看到方法修改对象字段后调用方读到新值，但参数改指新对象不替换调用方引用，即掌握此 KP。

## 易错点
调用方对象不会被参数重新赋值替换，因为方法只改了引用副本。
要替换对象须返回新对象并由调用方赋值；需要共享变化时修改对象状态。

## 延伸
用返回值显式表达替换结果，并比较不可变对象与可变对象的 API 设计。
在索引构建参数中区分共享词项状态与由调用方接收的新配置对象。

## 复现
