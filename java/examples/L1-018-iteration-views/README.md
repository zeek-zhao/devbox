# L1-018-iteration-views

<!-- coverage: pending -->

## 考点
对应 KP-JV-L1-18：迭代器安全删除、比较器排序、只读视图与不可变快照行为不同。
输出可见删除结果、固定排序、视图跟随源集合变化而快照保持原内容。

## 易错点
只读视图内容仍会变，因为它包装原集合而非复制；需固定查询快照用 copyOf，遍历删除用迭代器接口。
视图与快照都拒绝写入，但只有快照不随源集合后续修改而变化。

## 延伸
将查询结果排序后以 `List.copyOf` 固定为不可变返回值。
比较迭代器删除与直接修改集合在遍历期间的行为差异。
