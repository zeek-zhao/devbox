# L3-002-virtual-threads


## 考点
对应 KP-JV-L3-02：用 Java 21 虚拟线程执行器调度独立任务。
三个任务均确认 isVirtual 为 true，Future 收集结果为 `[1, 4, 9]` 且完成数为 3，说明等待与收集正确。

## 易错点
虚拟线程不会自动保证共享状态安全或带来提速，线程数量和耗时也不是正确性证据。
隔离每个任务的数据、逐个检查 Future 异常，只断言固定结果与虚拟线程属性。

## 延伸
把独立文档读取任务交给虚拟线程，并为每个任务定义超时与取消语义。
比较阻塞 IO 场景下虚拟线程与固定线程池的资源管理方式。

## 复现
TAG=latest scripts/run-example.sh java L3-002-virtual-threads
