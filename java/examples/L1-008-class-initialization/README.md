# L1-008-class-initialization


## 考点
对应 KP-JV-L1-08：构造器初始化实例状态，区分私有实例字段、共享静态字段与 `final` 引用。
看到两个实例的计数独立、静态实例数共享，且 final 引用指向的列表仍可变，即掌握此 KP。

## 易错点
final 对象仍可能改变，因为 `final` 只禁止引用重赋，并不冻结对象状态。
不可变模型还需限制字段修改并做防御性复制；封装状态可通过受控方法维护约束。

## 延伸
为索引配置设计不可变构造器，并比较列表防御性复制与可变配置对象。
检查静态初始化状态与实例生命周期状态各自适合承担的职责。
