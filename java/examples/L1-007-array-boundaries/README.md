# L1-007-array-boundaries


## 考点
对应 KP-JV-L1-07：数组长度固定，引用数组协变但运行时仍检查实际元素类型。
越界访问被检测、`Object[]` 写入整数到真实 `String[]` 被拒绝，即掌握此 KP。

## 易错点
协变赋值后写入会失败，因为真实数组元素类型仍为 `String`。
保留具体数组类型或改用类型安全集合，并在访问前检查下标范围。

## 延伸
比较固定长度数组与可增长集合在词项缓冲和批次输入中的适用场景。
练习处理空数组、首尾下标与运行时存储类型检查。
