# Java 知识点清单自检

三条探针分别取自 L1、L2、L3，验证对应判据的关键切片。在 `ghcr.io/zeek-zhao/devbox-java:latest` 镜像中关闭网络实跑，编译器与运行时均为 21.0.12.1。每段独立保存为 `Probe.java`，工作目录为 `/tmp/probe`；编译运行命令逐条相同：

```bash
javac -d /tmp/probe-out Probe.java && java -cp /tmp/probe-out Probe
```

探针不依赖 assert 开关；完整测试 harness 的 `java -ea` 契约另见 KP-JV-L2-05。文件 IO 探针只输出内容与状态，随机临时文件名及路径不进入输出。

### 探针 1：KP-JV-L1-01

<!-- probe:lang=java -->

```java
public class Probe {
  static class Box { int value = 1; }
  static void change(Box box) {
    box.value = 2;
    box = new Box();
    box.value = 9;
  }
  public static void main(String[] args) {
    Box box = new Box();
    Box alias = box;
    change(box);
    System.out.println("value: " + box.value);
    System.out.println("same: " + (box == alias));
  }
}
```

**实测输出**

```text
value: 2
same: true
```

### 探针 2：KP-JV-L2-08

<!-- probe:lang=java -->

```java
import java.nio.file.*;
import java.nio.charset.StandardCharsets;
public class Probe {
  public static void main(String[] args) throws Exception {
    Path file = Files.createTempFile("probe-", ".txt");
    try {
      Files.writeString(file, "词项", StandardCharsets.UTF_8);
      System.out.println("text: " + Files.readString(file, StandardCharsets.UTF_8));
      Files.writeString(file, "", StandardCharsets.UTF_8);
      System.out.println("empty: " + Files.readString(file, StandardCharsets.UTF_8).length());
    } finally { Files.delete(file); }
    System.out.println("exists: " + Files.exists(file));
    try { Files.readString(file); } catch (NoSuchFileException e) { System.out.println("missing: rejected"); }
  }
}
```

**实测输出**

```text
text: 词项
empty: 0
exists: false
missing: rejected
```

### 探针 3：KP-JV-L3-04

<!-- probe:lang=java -->

```java
import java.io.*;
import java.util.HexFormat;
public class Probe {
  public static void main(String[] args) throws Exception {
    ByteArrayOutputStream bytes = new ByteArrayOutputStream();
    try (DataOutputStream out = new DataOutputStream(bytes)) { out.writeInt(0x01020304); }
    byte[] data = bytes.toByteArray();
    System.out.println("bytes: " + HexFormat.ofDelimiter(" ").formatHex(data));
    try (DataInputStream in = new DataInputStream(new ByteArrayInputStream(data))) {
      System.out.println("value: " + in.readInt());
      try { in.readInt(); } catch (EOFException e) { System.out.println("truncated: rejected"); }
    }
  }
}
```

**实测输出**

```text
bytes: 01 02 03 04
value: 16909060
truncated: rejected
```
