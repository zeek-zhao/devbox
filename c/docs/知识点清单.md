# C 知识点清单

本清单描述 `c/examples/` 中用例本身，不描述毕业项目。层级表示考点复杂度；关键 API 和标准条款用于定位可验证的语言或库行为。

> 当前目录共有 78 个用例：77 个 `L1`/`L2`/`L3` 编号用例，以及独立通路验证层 `L0-hello/`。L0 表示镜像与 runner 通路验证，不属于知识点难度层级。
