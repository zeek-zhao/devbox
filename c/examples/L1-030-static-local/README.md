# L1-030-static-local —— 函数内静态变量跨调用保留状态

## 考点

- 局部 `static` 对象具有静态存储期，只初始化一次。
- 静态局部变量仍然可变，不等同于常量。

## 为什么这么写

同一函数连续调用三次并逐次打印递增结果，直接观察变量的初始化次数与生命周期。

## 易错点

- `static` 在这里不是 `const`；每次调用都会修改同一个对象。
- 静态局部变量的名字仍只在声明它的块作用域内可见。

## 运行

```bash
TAG=latest scripts/run-example.sh c L1-030-static-local
```
