# L1-022-memory-leak-pattern —— 用统一清理出口收拢错误路径

## 考点

- 多次分配失败时可跳转到同一个清理标签。
- 对空指针调用 `free` 安全，因此清理代码不需要重复判断每个分配是否成功。

## 为什么这么写

两处分配失败都跳到 `cleanup`，成功和失败都经过相同的释放语句，避免每个提前返回分支各自复制清理逻辑。

## 易错点

- 清理顺序应按资源依赖关系处理；本例两块独立内存都必须释放。
- 不要从错误路径跳过初始化就使用资源；指针先初始化为空，统一释放才安全。

## 运行

```bash
TAG=latest scripts/run-example.sh c L1-022-memory-leak-pattern
```
