# L2-012-file-io —— 往返写读文件并逐字节验证

## 考点

- 检查 `fopen` 返回值，并使用 `fwrite`、`fread` 与 `fclose` 完成文件生命周期。
- 用长度和逐字节比较验证读回数据与原始字节完全相同。

## 为什么这么写

测试文件建在每个用例独立的临时目录，程序只在所有读回检查成功后输出 `OK`，随后删除文件。

## 易错点

- 只检查 `fwrite` 忽略缓冲或磁盘错误；还需检查写入字节数和关闭状态。
- 把字符串长度误当成缓冲区大小会漏掉结尾字节或越界读取。

## 运行

```bash
TAG=latest scripts/run-example.sh c L2-012-file-io
```
