# L3-008-binary-heap —— 用数组实现最小二叉堆

## 考点

- push 时向上调整堆序。
- pop 时用末尾元素替换根并向下调整，最终按序取出所有数据。

## 为什么这么写

堆用连续数组表示，父子下标关系直接体现完全二叉树的紧凑布局。

## 易错点

- 根节点没有父节点；上浮循环条件必须先判断下标大于零。
- 下沉时先确认左子节点存在，再读取子节点值。

## 运行

```bash
TAG=latest scripts/run-example.sh c L3-008-binary-heap
```
