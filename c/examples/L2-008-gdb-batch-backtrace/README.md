# L2-008-gdb-batch-backtrace —— 在无交互模式下检查崩溃调用栈

## 考点

- 使用 `-g -O0` 编译，保留 GDB 可读的函数符号。
- 批处理运行崩溃程序并从回溯中确认故障函数名。

## 为什么这么写

GDB 的完整输出被保存在临时日志中，脚本只对稳定的函数名作断言，不依赖行号和平台相关提示文本。

## 易错点

- 未启用调试信息或使用优化会让栈帧缺少源代码符号。
- 只看 GDB 的退出码不能确认回溯中出现了预期故障点。

## 运行

```bash
TAG=latest scripts/run-example.sh c L2-008-gdb-batch-backtrace
```
