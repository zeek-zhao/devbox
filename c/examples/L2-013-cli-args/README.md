

# L2-013-cli-args —— 手写解析长短命令行选项

## 考点

- 从 `argc`、`argv` 解析 `--name=X` 参数和值。
- 独立识别 `-v` 开关，并为未知或缺失参数返回错误。

## 为什么这么写

解析器只支持本例明确规定的两种参数，避免依赖 POSIX `getopt`，同时用固定参数验证结构化结果。

## 易错点

- 先检查参数前缀再访问后续字符，否则短参数可能造成越界读取。
- 把 `--name=` 的空值和缺少整个选项混为一谈，会让错误输入悄悄通过。

## 运行

```bash
TAG=latest scripts/run-example.sh c L2-013-cli-args
```
