# L1-031-internal-linkage —— 静态文件作用域对象各自拥有状态

## 考点

- 文件作用域的 `static` 对象具有内部链接，只能由本翻译单元中的名字引用。
- 不同翻译单元里同名的静态对象是互不相关的对象。

## 为什么这么写

分别编译两个定义了同名静态计数器的源文件，再链接调用；两边各自从 1 递增，证明状态并未共享。

## 易错点

- 同名 `static` 对象不会造成外部符号冲突，也不会因此变成同一个对象。
- 头文件中定义非 `static` 全局对象并被多个源文件包含，会导致重复定义。

## 运行

```bash
TAG=latest scripts/run-example.sh c L1-031-internal-linkage
```
