

# L1-023-double-free-guard —— 释放后置空使重复清理安全

## 考点

- 已释放对象的指针不能再解引用或再次释放。
- `free(NULL)` 是标准定义的安全空操作。

## 为什么这么写

释放后立即将指针置空，并再次调用 `free`，把常见清理模式落实为可运行的行为验证。

## 易错点

- 指针置空不能撤销先前释放，也不能让对其他悬空别名的访问变安全。
- 不要在第一次 `free` 后通过旧指针打印值。
