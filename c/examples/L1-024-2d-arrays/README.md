# L1-024-2d-arrays —— 对比二维数组与指针数组的实际布局

## 考点

- `int[3][4]` 是连续的三行数组，每行包含四个 `int`。
- `int *[3]` 是三个指针组成的数组，元素大小与 `int` 不同。

## 为什么这么写

同时打印矩阵总大小、行大小、行地址跨度和指针数组大小，观测对象布局，而不是仅凭声明形式推断。

## 易错点

- 二维数组表达式衰变为「指向 4 个 `int` 的数组的指针」，不是 `int **`。
- `int **` 与 `int[3][4]` 的布局、指针算术均不同，不能互换传参。
