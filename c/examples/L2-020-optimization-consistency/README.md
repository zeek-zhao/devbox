# L2-020-optimization-consistency —— 比较 O0 与 O2 的定义良好行为

## 考点

- 同一份程序分别以 `-O0` 和 `-O2` 编译运行。
- 对固定范围内的整数平方求和，验证两种优化级别输出一致。

## 为什么这么写

程序使用确定范围内的有符号整数运算，不包含未定义行为；脚本通过比较真实运行输出而不是硬编码替代程序结果。

## 易错点

- 有符号溢出等未定义行为会允许优化器改变程序表现，不能拿它作为一致性正例。
- 只比较编译产物而不运行，无法验证优化后的可观察行为。

## 运行

```bash
TAG=latest scripts/run-example.sh c L2-020-optimization-consistency
```
