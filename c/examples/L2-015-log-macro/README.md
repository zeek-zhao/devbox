# L2-015-log-macro —— 使用源位置宏并规范化动态行号

## 考点

- 日志宏把 `__FILE__`、`__LINE__` 和消息组合到同一条记录。
- 运行脚本归一化源文件名与行号，再输出业务日志。

## 为什么这么写

源代码行号会因维护改动而变化；归一化只保留“宏带有源位置”的判据，避免脆弱地固定行号。

## 易错点

- 宏参数未加括号或格式串不匹配，可能在调用点产生意外求值或格式错误。
- 将原样行号写入期望输出会让无关的源码排版改动导致用例失败。

## 运行

```bash
TAG=latest scripts/run-example.sh c L2-015-log-macro
```
