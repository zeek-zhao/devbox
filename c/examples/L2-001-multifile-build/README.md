

# L2-001-multifile-build —— 多个翻译单元正确编译与链接

## 考点

- `main.c` 通过头文件使用另一个翻译单元提供的函数。
- 一次编译命令同时编译实现并完成链接，输出可执行文件。

## 为什么这么写

声明放在头文件、定义放在 `.c` 文件，避免调用方依赖实现细节。把产物放到临时目录，不会污染源码树。

## 易错点

- 只编译 `main.c` 会产生未定义引用；实现文件也必须参与链接。
- 在多个 `.c` 文件中定义同一个非 `static` 函数会造成重复符号。

## 运行

```bash
TAG=latest scripts/run-example.sh c L2-001-multifile-build
```
