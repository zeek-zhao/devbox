# L3-015-float-precision —— 用相对误差判断浮点近似相等

## 考点

- 展示 `0.1 + 0.2` 与 `0.3` 的精确比较结果。
- 按两数尺度计算相对误差，而不是使用固定绝对误差。

## 为什么这么写

误差阈值随被比较数的绝对值缩放，并对接近零的尺度设下限。

## 易错点

- 十进制小数通常不能被二进制浮点精确表示。
- 绝对误差阈值会对很大或很小的量给出不合比例的判断。

## 运行

```bash
TAG=latest scripts/run-example.sh c L3-015-float-precision
```
