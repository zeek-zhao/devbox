# L3-013-crc32 —— 用查表法计算 CRC-32

## 考点

- 使用反射多项式 `0xEDB88320` 生成 256 项查找表。
- 对标准测试字符串计算并校验 CRC-32。

## 为什么这么写

运行时从多项式生成表，避免把表格常量硬编码成不可审阅的 256 个值。

## 易错点

- 反射 CRC 每轮对最低位测试，初值和最终异或都为 `0xffffffff`。
- `"123456789"` 的已知结果是 `0xcbf43926`。

## 运行

```bash
TAG=latest scripts/run-example.sh c L3-013-crc32
```
