# L3-014-bitboard —— 用 64 位字数组表示 200 位集合

## 考点

- 将元素索引拆分为字索引 `i / 64` 和位索引 `i % 64`。
- 设置并打印跨越多个字边界的集合位图。

## 为什么这么写

选取分布在不同 64 位字的元素，使字索引和位索引反向时的错误能直接改变结果。

## 易错点

- 字内偏移不能误写为 `i / 64`。
- 左移的左操作数必须是无符号 64 位整数。

## 运行

```bash
TAG=latest scripts/run-example.sh c L3-014-bitboard
```
