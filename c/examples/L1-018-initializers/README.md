

# L1-018-initializers —— 用指定初始化器按字段名初始化结构体

## 考点

- 指定初始化器按成员名赋值，不依赖成员在初始化列表里的顺序。
- 结构体未显式初始化的成员会被零初始化。

## 为什么这么写

把 `.y` 写在 `.x` 前面，再同时打印两个字段，能直接验证成员名而非列表位置决定赋值。普通位置初始化写不出这种顺序。

## 易错点

- 指定初始化器是 C99 起的语法，不是 C++ 的通用写法。
- 字段名拼错或字段类型不匹配会在严格编译选项下暴露。

## 运行

```bash
TAG=latest scripts/run-example.sh c L1-018-initializers
```
