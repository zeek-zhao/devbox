# L1-020-malloc-free —— 分配、使用并释放动态数组

## 考点

- `malloc` 按字节数分配数组存储，返回值必须检查。
- 分配的数组可按普通下标访问，结束使用后由调用方 `free`。

## 为什么这么写

程序写入五个动态分配的元素后再读回求和；输出依赖真实分配与访问，而不是只打印固定常量。

## 易错点

- 使用 `sizeof *values` 与元素类型绑定，避免修改指针类型后忘记同步分配大小。
- 不要用 `malloc(0)` 的返回值判断分配是否成功；零大小请求的结果允许因实现而异。

TAG=latest scripts/run-example.sh c L1-020-malloc-free
