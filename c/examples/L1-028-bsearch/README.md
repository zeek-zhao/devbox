# L1-028-bsearch —— 先排序再进行二分查找

## 考点

- `bsearch` 使用与排序一致的元素大小和比较关系。
- 查找结果用空指针表示未命中，非空时指向数组中的匹配元素。

## 为什么这么写

输入数组先经 `qsort` 排序，再分别查找存在的 7 和不存在的 6，输出命中值与缺失状态。

## 易错点

- `bsearch` 的数组必须按同一比较规则预先排序。
- 不要解引用未命中时返回的空指针。

## 运行

```bash
TAG=latest scripts/run-example.sh c L1-028-bsearch
```
