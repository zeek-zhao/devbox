# L1-025-vla-limits —— 让数组长度在运行期确定

## 考点

- 变长数组的长度可以来自运行期表达式。
- `sizeof` 对 VLA 在运行期求值，结果随实际长度变化。

## 为什么这么写

`count` 是普通运行期变量，数组大小和 `sizeof` 都依赖它；读取首元素则确认声明出的数组确实可用。

## 易错点

- C11 起 VLA 支持是可选特性，不能假设所有 C 实现都支持。
- 不要把不受控的大长度放在自动存储期数组上，可能耗尽栈空间。

## 运行

```bash
TAG=latest scripts/run-example.sh c L1-025-vla-limits
```
