# L2-019-struct-by-value-abi —— 按值传递不同大小的结构体

## 考点

- 将一个小结构体和一个较大结构体按值传入函数。
- 打印各自的 `sizeof` 与被调用函数读取到的字段结果。

## 为什么这么写

函数只读取参数副本，不依赖具体寄存器传递规则；示例把结构体尺寸和语义结果分开呈现。

## 易错点

- 按值传递会复制结构体，较大对象的热路径通常更适合使用指针或只读指针。
- 结构体尺寸可能受 ABI 和对齐规则影响，不应假设所有平台布局相同。

## 运行

```bash
TAG=latest scripts/run-example.sh c L2-019-struct-by-value-abi
```
