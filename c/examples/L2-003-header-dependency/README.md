

# L2-003-header-dependency —— 互相包含的头文件仍可安全使用

## 考点

- 两个头文件互相包含时，用 include guard 阻止递归展开。
- 主程序同时包含头文件，并调用另一个头文件声明的实现。

## 为什么这么写

`alpha.h` 通过前置声明打断类型依赖，`beta.h` 定义共享结构；头文件自身负责声明依赖，不靠调用方碰巧先包含某个文件。

## 易错点

- 头文件缺少保护宏会在相互包含时重复定义类型。
- 依赖头文件没有声明函数时，调用方可能出现隐式声明诊断或接口不一致。

## 运行

```bash
TAG=latest scripts/run-example.sh c L2-003-header-dependency
```
