# L2-016-print-formats —— 核对 printf 的精度、补零与动态宽度

## 考点

- `%.3f` 控制浮点输出精度。
- `%08x` 将十六进制数补零到固定宽度，`%*d` 从参数读取字段宽度。

## 为什么这么写

每组格式串都和对应的 C 参数类型匹配，并分别输出，便于期望文件直接覆盖格式行为。

## 易错点

- `%x` 要求对应的无符号整数参数，错误类型会造成未定义行为。
- `%*d` 需要先传宽度再传整数；少一个参数会使后续读取错位。

## 运行

TAG=latest scripts/run-example.sh c L2-016-print-formats
