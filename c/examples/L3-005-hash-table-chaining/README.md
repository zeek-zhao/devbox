# L3-005-hash-table-chaining —— 实现可删除的拉链哈希表

## 考点

- 用桶数组和链表保存整数键值。
- 验证批量插入、查找、删除后的命中和剩余数量。

## 为什么这么写

桶数组在本例中固定大小，节点单独分配；删除只改链，不搬动其它桶节点。

## 易错点

- 删除链表头节点时必须更新桶头。
- 计算哈希索引前处理负键，避免负数取模产生负下标。

## 运行

```bash
TAG=latest scripts/run-example.sh c L3-005-hash-table-chaining
```
