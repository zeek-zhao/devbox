# L3-020-matrix-blocking —— 分块计算矩阵乘积并校验结果

## 考点

- 实现朴素和分块两种矩阵乘法。
- 对 64×64 矩阵比较完整结果校验和，并测量各自耗时。

## 为什么这么写

矩阵输入确定，校验和不依赖机器；时间仅在运行中测量，不写入逐行匹配的期望输出。

## 易错点

- 分块边界使用 `min(start + block, size)`，确保尺寸不是块长倍数时也不越界。
- 两种实现必须使用同一乘法顺序和输入数据。

## 运行

```bash
TAG=latest scripts/run-example.sh c L3-020-matrix-blocking
```
