# L3-012-varint —— 编解码无符号变长整数

## 考点

- 每个 varint 字节携带 7 位数据和一个延续位。
- 编码 300 并解码，验证字节序列和原值。

## 为什么这么写

用小型字节缓冲区展示跨越一个 7 位组的编码，同时检查解码是否消费了全部字节。

## 易错点

- 最后一个字节的最高位必须为零。
- 解码移位前要限制输入长度，避免移位越界。

## 运行

```bash
TAG=latest scripts/run-example.sh c L3-012-varint
```
