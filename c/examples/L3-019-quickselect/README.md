# L3-019-quickselect —— 用三数取中选择第 k 小元素

## 考点

- 使用分区而非完整排序选择第 k 小元素。
- 通过首、中、尾三数取中选择 pivot，并累计比较次数。

## 为什么这么写

分区后只递归/迭代包含目标下标的一侧，比较计数也能证明操作确实执行。

## 易错点

- k 是从零开始的数组下标，不是从一开始的名次。
- 每次分区都必须缩小搜索区间，否则可能陷入死循环。

## 运行

```bash
TAG=latest scripts/run-example.sh c L3-019-quickselect
```
