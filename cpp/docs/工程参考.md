# C++ 工程参考（reference）

> 本轨构建/运行/镜像/依赖/环境变量/计数口径的查表页。只陈述事实与真本出处，
> 不讲怎么学、怎么排障。版本号一律引用 `images/versions.env` 变量名，不写字面量
> （契约见 [docs/11](../../docs/11-知识点清单增强规范.md) §4.4）。

## 1. 目录结构

| 路径 | 职责 |
|---|---|
| `cpp/examples/` | 用例目录（92 个：L0-hello 1 个 + L1–L4 编号用例 76 个 + E 类错误处理用例 15 个） |
| `cpp/labs/` | 排障演练 lab（T-001-asan-heap-overflow）；lab 不计入 examples 用例计数 |
| `cpp/project/` | 毕业项目样板「C++ 文本索引器」（CMake 工程：mmap 倒排索引 + ctest + bench） |
| `cpp/docs/` | 本轨文档（G1–G5 指南 + 用例编写规范 + 清单 + 本卡新增四篇，见 [INDEX](INDEX.md)） |

## 2. 镜像与版本真本

| 事实 | 值 | 真本出处 |
|---|---|---|
| cpp 轨镜像层 | `cpp` 层（`devbox-cpp` 镜像） | `images/lang-images.tsv` |
| 镜像 registry 前缀 | `${REGISTRY}` | `images/versions.env` `REGISTRY=` |
| GCC 主版本 | `${GCC_MAJOR}` | `images/versions.env` `GCC_MAJOR=` |
| clang / clang-format 主版本 | `${CLANG_MAJOR}` / `${CLANG_FORMAT_MAJOR}`（两者须同步） | `images/versions.env` |
| CMake 最低版本 | `${CMAKE_MIN_VERSION}`（项目 `cmake_minimum_required(VERSION 3.28)` 与之对齐） | `images/versions.env` `CMAKE_MIN_VERSION=` |
| 本地镜像 tag | `local`（runner 默认） | `scripts/run-example.sh` `TAG="${TAG:-${IMAGE_TAG:-local}}"` |

> 版本事实以 `images/versions.env` 为唯一真本；本表只写变量名，改版本不改本表。
> 镜像与 runner 的口径详见 [docs/01-镜像体系](../../docs/01-镜像体系.md)。

## 3. 命令速查

| 命令 | 作用 |
|---|---|
| `TAG=latest scripts/run-example.sh cpp <ID>` | 跑单个用例（如 `cpp E-001-exception-hierarchy`），与 `expected.txt` 逐行比对 |
| `scripts/run-example.sh cpp --list` | 列出 cpp 轨全部用例 ID |
| `TAG=latest scripts/run-example.sh cpp E-001-exception-hierarchy --keep` | 保留容器，便于 `docker exec` 进去复现 |
| `cd cpp/project && cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j` | 配置并构建毕业项目样板 |
| `cd cpp/project && ctest --test-dir build --output-on-failure` | 跑项目测试 |
| `cd cpp/project && ./build/bench_index <file> <word>` | 跑基准计时 |

runner 契约：每个用例目录必须含 `run.sh`（只往 stdout 打业务输出）、
`expected.txt`（逐行精确，忽略行尾空白）、`README.md`（考点说明）——
真本 `scripts/run-example.sh` 头部注释。

## 4. 环境变量

| 变量 | 含义 | 缺省 |
|---|---|---|
| `TAG` | 用例镜像 tag；与 CI 的 `IMAGE_TAG` 是同一个值的两个名字 | `local` |
| `IMAGE_TAG` | CI 传入的镜像 tag（`TAG` 的别名） | 未设时 `TAG` 生效 |
| `REGISTRY` | 镜像 registry 前缀，覆盖时 runner 用它拼镜像名 | `${REGISTRY}`（versions.env） |
| `ASAN_OPTIONS` | ASan 行为开关（sanitizer 用例与 lab 依赖） | 工具默认 |

| 口径 | 值 | 说明 |
