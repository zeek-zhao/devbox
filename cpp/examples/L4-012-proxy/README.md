# L4-012-proxy


## 考点

对应 KP-L4-12：用代理对象控制对目标对象的访问，代理与目标实现同一接口。

可观察判据：代理在首次调用时才创建真实对象（延迟加载），并累计调用次数；输出固定次数。

## 为什么这样写

`main.cpp` 第 5–19 行声明统一查询接口和真实查询，由真实对象构造函数更新构造计数。
第 21–35 行的代理私有持有 `unique_ptr<Query>`，第 23–28 行首次访问才创建目标，随后每次累计调用并通过基类指针委托；没有向调用方暴露目标。
第 38–47 行通过 `Query&` 调用代理两次，分别观察构造数 0、1、1 和调用数 0、1、2。
若提前创建目标，`before: constructions=0, calls=0` 中构造数会变成 1；若每次重建，第二次构造数会变成 2；若绕过计数，调用数不会累计到 2。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh cpp L4-012-proxy
```
