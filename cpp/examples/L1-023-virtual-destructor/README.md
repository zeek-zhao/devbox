# L1-023-virtual-destructor

<!-- coverage: pending -->

## 考点
对应 KP-L1-23：通过基类指针销毁派生对象时，虚析构保证派生析构函数执行。
观察 trait 的 `false`/`true` 和对应析构标记，说明理解虚析构的作用。

## 易错点
无虚析构的基类不能安全地通过基类指针删除派生对象，这会触发未定义行为。
先检查基类析构是否为虚函数；示例只直接销毁非虚场景的派生对象。

## 延伸
为多态基类建立“虚析构或受保护非虚析构”的设计约定。
进一步观察派生对象析构顺序，以及智能指针如何通过基类类型管理对象。
