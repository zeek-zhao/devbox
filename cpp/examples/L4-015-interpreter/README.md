# L4-015-interpreter


## 考点

对应 KP-L4-15：用类层次表示文法规则，对输入递归解释求值。

可观察判据：数字终结符与加减非终结符组合成表达式树，对固定输入输出固定结果；非法字符返回错误。

## 为什么这样写

代码位置（`main.cpp`）：第 11–50 行定义多态表达式节点，第 56–75 行组装表达式树，第 107–117 行求值并测试非法输入。

`Parser` 按 `数字 ((+|-) 数字)*` 文法构建左结合表达式树，支持多位非负数字和空格。本例使用小整数，求值结果在 `int` 范围内。`Number` 是终结符，`Add`、`Subtract` 持有两个抽象 `Expression` 子节点；它们的 `interpret()` 递归通过虚函数求值。解析阶段选择运算符，求值阶段不判断节点类型。

把 `Subtract::interpret()` 的递归运算拆掉，第一行结果 `9` 就会改变。第二次实际解析 `8 + x` 并捕获解析器抛出的异常；若非法字符未被拒绝，则输出或退出码不匹配。
