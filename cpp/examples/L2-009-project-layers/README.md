# L2-009-project-layers

<!-- coverage: pending -->

## 考点
对应 KP-L2-09：命令入口调用索引逻辑，索引逻辑再调用存储接口，并分别报告各层查询结果。
看到同一查询得到一致的存储、索引、命令结果，说明能沿公开接口分层且逻辑不依赖命令行全局状态。

## 易错点
业务层直接读取全局状态会让索引难以单独测试，也妨碍复用。
把存储对象通过索引接口持有，并让命令层只依赖索引；头文件依赖方向是 command → index → storage。

## 延伸
可以为存储接口加入内存实现和文件实现，让索引层在不变更查询逻辑时切换后端。
再单独构造索引对象测试命中、未命中和边界查询。
