# L1-005-move-semantics


## 考点
对应 KP-L1-05：移动构造将拥有的缓冲区转移给目标对象。
目标仍可读取原值，源对象未被读取内容且随后正常析构，说明移动后可安全销毁。

## 易错点
`std::move` 只转换值类别，不会独自转移资源；类型需提供移动操作。
移动后源对象内容未指定，不读取或断言其内容，只依赖其可析构等有效操作。

## 延伸
为缓冲区补充移动赋值，并检查自移动赋值时仍能安全析构。
比较 `std::unique_ptr` 和容器如何利用移动避免昂贵的深拷贝。
