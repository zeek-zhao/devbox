# L4-020-state


## 考点

对应 KP-L4-20：把状态相关行为分散到状态对象，上下文在状态切换后行为随之改变。

可观察判据：上下文持有状态指针，两次 `request()` 触发状态切换，输出固定状态序列。

## 为什么这样写

代码位置（`main.cpp`）：第 14–36 行定义具体状态转换，第 45–52 行委托并替换状态指针，第 58–65 行执行两次请求。

上下文 `Task` 持有 `unique_ptr<State>`，`request()` 委托当前状态的虚函数 `handle()` 获取下一状态，再替换指针。`Pending` 生成 `Running`，`Running` 生成 `Done`，终态保持完成状态。上下文不判断状态类型；先完成虚函数调用再销毁旧状态，避免方法执行中删除自身。

三行标签均由当前状态的虚函数 `name()` 返回。若删掉上下文的指针替换，第二、三行都会停在 `pending`；若拆掉 `Running::handle()` 的转换，第三行不会成为 `done`。空状态和无效转换显式抛出异常。
