# L2-012-ci-build-test


## 考点
对应 KP-L2-12：脚本删除并重建临时构建目录，配置、编译后运行自动化测试。
看到 `clean-build: ok` 与 `tests: ok`，说明用例不是依赖旧构建产物而能完成干净验收。

## 易错点
只做增量构建会掩盖漏加源文件或本机遗留依赖，导致全新检出时失败。
每次从临时目录零构建，并让 CTest 失败时保留诊断且向外返回非零。

## 延伸
可以把静态检查、多个编译器和依赖配置加入同一套自动化任务。
再从全新检出验证脚本只依赖被跟踪的源文件和明确声明的工具链。

## 复现
TAG=latest scripts/run-example.sh cpp L2-012-ci-build-test
