# L4-018-memento


## 考点

对应 KP-L4-18：在不破坏封装的前提下保存并恢复对象内部状态。

可观察判据：原发器 `save()` 返回备忘录，改字段后 `restore()` 恢复原值，输出固定前后值；备忘录对外只读。

## 为什么这样写

代码位置（`main.cpp`）：第 9–20 行定义只读备忘录，第 28–32 行保存和恢复，第 41–43 行验证只读类型约束，第 46–56 行修改及回滚。

`Editor::save()` 按值复制文本和光标到 `Memento`，`restore()` 读取备忘录恢复两个私有字段。备忘录的构造器私有、字段为 `const`，对外只有只读访问器；编译期断言确认不能赋值且文本访问返回常量引用。调用方只保管快照，不修改历史状态。

删掉 `restore()` 中任一字段恢复，第三行就不能完整回到 `draft, cursor=2`。第四行读取快照，验证原发器修改没有影响历史；若快照引用原发器的字段，历史输出会随修改改变。
