# L1-032-numeric-overflow

<!-- coverage: pending -->

## 考点
对应 KP-L1-32：无符号加法按模回绕，内建检查器可检测有符号加法和乘法溢出。
看到回绕结果为零、两种有符号溢出均被报告，且 `-1 < 1u` 转换后为假，即可说明掌握边界行为。

## 易错点
直接执行有符号溢出会触发未定义行为，结果不能依赖；用溢出检查器判断而不计算溢出的表达式。
有符号数与无符号数比较时负数会转换为无符号数；比较前应校验范围并统一类型。

## 延伸
可把同类边界检查用于文档偏移量，先验证偏移和长度不会超过缓冲区边界。
还可比较显式范围检查、`std::in_range` 与编译器溢出内建函数的适用情形。
