# L1-003-lifetime-copy-control

<!-- coverage: pending -->

## 考点
对应 KP-L1-03：自定义资源对象通过深拷贝构造、赋值和析构控制资源生命周期。
输出显示修改赋值目标不改变原对象或拷贝，并按局部作用域顺序销毁三份资源。

## 易错点
仅定义析构函数却保留浅拷贝，会让多个对象释放同一资源。
资源所有者应实现匹配的拷贝操作，赋值先复制新值再替换旧资源。

## 延伸
补齐拷贝构造并实现完整的三法则，再比较用 `std::vector` 管理资源的方式。
增加自赋值测试，并验证赋值期间分配失败时原对象仍然有效。
