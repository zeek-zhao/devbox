# L1-001-references-pointers


## 考点
对应 KP-L1-01：引用必须绑定到对象，指针可以为空。
看到空指针可明确识别、引用能访问已绑定对象，说明理解了可空性差异。
数组内指针可按元素移动；不要把这种算术用于无关对象。

## 易错点
把“指针当前非空”误当成指针永远有效，会导致悬垂访问。
只在对象仍存活且数组边界内进行指针算术；可空参数先检查再解引用。

## 延伸
练习用 `std::span` 表示连续数据及其边界，避免单独传递裸指针和长度。
比较必需参数用引用、可选参数用指针或 `std::optional` 的接口表达。
