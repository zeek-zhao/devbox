# L2-004-file-io


## 考点
对应 KP-L2-04：在临时目录创建并读写文件，检查缺失输入和无法创建文件的结果。
看到正常内容、两种失败状态及排序后的文件名，即说明掌握文件 IO 与路径处理。

## 易错点
不检查流的打开状态会把文件不存在或路径不可写误当成空内容，导致错误结果。
读写后检查流状态，并只输出相对文件名，避免把机器相关的绝对路径写进结果。

## 延伸
可继续使用 `std::error_code` 区分 filesystem 错误，并处理编码和大文件分块读取。
再为目录遍历加入扩展名筛选，并测试符号链接及嵌套目录的策略。
