# L4-022-template-method

<!-- coverage: pending -->

## 考点

对应 KP-L4-22：父类固定算法骨架，把可变步骤留给子类实现。

可观察判据：基类非虚 `run()` 固定调用顺序，两个子类各自实现步骤，输出固定骨架与子类结果。

## 为什么这样写

代码位置（`main.cpp`）：第 7–11 行固定非虚骨架，第 14–25 行定义可变步骤，第 27–34 行通过基类指针运行两个子类。

`Pipeline::run()` 是公开非虚方法，固定执行准备、可变步骤、校验。受保护的纯虚 `step()` 分别由两个子类实现；`main()` 经 `const Pipeline*` 调用骨架，骨架内部实际发生虚函数分发，不直接调用具体类步骤。

删掉骨架中的准备或校验，对应的第一/第三行和第四/第六行会消失；若不调用虚步骤，第二行 `parse text` 和第五行 `build index` 无法由子类产生。非虚骨架保证经基类调用时子类不能改写调用顺序。
