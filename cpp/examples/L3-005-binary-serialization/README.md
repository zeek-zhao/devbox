# L3-005-binary-serialization


## 考点
对应 KP-L3-05：手工编码固定宽度小端字段，并校验魔数、版本、长度和校验和。
看到固定字节序列可解码回原值，且损坏载荷被拒绝，说明格式边界得到验证。

## 易错点
直接写原生结构体会把填充、字节序和 ABI 带入磁盘格式；逐字节编码固定宽度字段。
只检查魔数会接受数据损坏；解码时校验长度与校验和，任一不符就拒绝。

## 延伸
为格式增加显式版本迁移，并定义未知版本的兼容策略。
扩展截断、超长长度和校验字段损坏的拒绝测试。
