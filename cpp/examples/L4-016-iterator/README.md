## 考点

对应 KP-L4-16：提供顺序访问聚合元素的统一方式，不暴露内部结构。

可观察判据：自定义迭代器支持 `begin/end` 与范围 for，遍历得到固定序列；耗尽后与 `end()` 比较相等。

## 为什么这样写

代码位置（`main.cpp`）：第 19–38 行实现迭代器操作，第 49–50 行提供遍历入口，第 58–78 行实际遍历、比较终点并触发边界异常。

`Sequence` 隐藏底层 `vector`，仅提供只读 `begin/end`。嵌套 `Iterator` 实现解引用、前后置递增和包含聚合身份的相等比较，并以 `static_assert` 验证前向迭代器接口。聚合在遍历期间保持不变，且比迭代器活得更久。

第一行由范围 for 实际遍历得到；第二行先逐步递增至耗尽，再计算与 `end()` 的比较结果。若递增或终点定义错误，序列、比较结果或退出行为会改变。第三行真的解引用耗尽迭代器并捕获边界异常，不是模拟异常输出。
