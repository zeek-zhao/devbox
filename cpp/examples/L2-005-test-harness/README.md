# L2-005-test-harness


## 考点
对应 KP-L2-05：轻量 `CHECK` 宏统计成功与失败断言，覆盖正常、边界及未命中路径。
全部检查通过时输出通过数和零失败；任一检查失败都会打印诊断并以非零状态退出。

## 易错点
用 `assert` 写测试会在定义 `NDEBUG` 的构建中被整体关闭，测试可能假通过。
使用不依赖构建模式的检查宏、统计每次断言，并在失败时明确返回非零。

## 延伸
可为检查宏增加表达式和值的诊断，再按测试组显示独立的通过和失败计数。
也可将测试函数从 `main` 拆出，接入 CTest 而保持同一套断言逻辑。
