# L1-021-enum-class


## 考点
对应 KP-L1-21：用 `enum class` 表达有限状态，并显式转换为整数。
看到明确的状态名称和序列化整数值，说明状态表达与转换边界清晰。

## 易错点
`enum class` 不会隐式转成整数，直接用于整数接口会编译失败。
需要序列化时显式 `static_cast`，不要依赖隐式转换或裸整数状态。

## 延伸
为持久化状态定义稳定的整数编码，并处理未知或保留的枚举值。
比较强类型枚举与旧式 `enum` 在作用域和类型安全上的差异。
