# L4-003-abstract-factory


## 考点

对应 KP-L4-03：一个工厂接口成组创建一族相互配套的产品，切换工厂即切换整套实现。

可观察判据：两个具体工厂各自创建按钮与文本框，同一工厂产出的两个产品 `family()` 标签一致，另一工厂标签不同。

## 为什么这样写

`main.cpp` 第 10–30 行将族标签放入抽象产品与工厂的类型参数，第 52–70 行由两个具体工厂分别创建整族产品。
第 73–94 行的 `Panel<Family>` 只接受同族按钮和文本框，静态断言验证混入另一族文本框不能构造面板。
第 97–111 行通过工厂基类指针创建、通过产品基类指针调用 `family()`，实际比较族标签。
若把暗色文本框的 `family()` 错写成 `light`，其 `matching family: true` 会变成 `false`；
若取消族类型约束，混用产品将使静态断言失败，而不是仍然悄悄运行。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh cpp L4-003-abstract-factory
```
