# L4-023-visitor

<!-- coverage: pending -->

## 考点

对应 KP-L4-23：把作用于对象结构的操作从元素类中分离，新增操作不改元素。

可观察判据：两个元素 `accept` 两个访问者，四种组合各输出固定文本；新增访问者无需改元素。

## 为什么这样写

代码位置（`main.cpp`）：第 8–19 行定义双分派接口，第 25–27 和 37–39 行实现元素转发，第 45–64 行定义两种操作，第 67–78 行遍历四种组合。

`Text`、`Number` 实现抽象 `Element::accept()`，内部只调用 `visitor.visit(*this)`。元素的动态类型先决定 `accept()`，随后具体元素类型选择 `visit` 重载，访问者动态类型再决定操作实现，形成双分派。`DescribeVisitor` 展示内容，独立的 `MeasureVisitor` 计算文本或数字表示的字符数，没有改动元素，也没有类型判断。

`main()` 双重循环只持有元素和访问者的基类指针，实际执行全部四种组合。删掉元素的转发将无法产生对应两行；若只保留一个访问者，第三、四行度量输出会消失。度量值来自元素数据，而非写死 `3`、`2`。
