# L4-017-mediator

<!-- coverage: pending -->

## 考点

对应 KP-L4-17：用中介者集中协调多个同事对象的交互，同事之间不直接引用。

可观察判据：两个同事只持有中介者指针，发送消息后中介者转发给另一同事，输出固定接收顺序。

## 为什么这样写

代码位置（`main.cpp`）：第 17–31 行定义仅依赖中介者的同事，第 42–52 行转发消息，第 57–66 行注册并依次发送。

`Colleague` 仅保存 `Mediator*` 和自己的名字，不保存另一同事的引用。`send()` 经抽象中介者虚函数转发；`ChatRoom` 保存注册名单并排除发送者，实际调用另一同事的 `receive()`。重复注册和未注册发送者会抛出异常。这里名单是非拥有指针，只在两个同事均存活期间发送。

`main()` 依次让 Alice、Bob 发送，接收日志来自中介者调用而非发送方。删除 `ChatRoom::send()` 的转发，两行接收日志都会消失；删除发送者过滤，则会多出给自己的接收日志。
