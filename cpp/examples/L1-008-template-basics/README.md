# L1-008-template-basics


## 考点
对应 KP-L1-08：同一个函数模板分别处理 `int` 和 `std::string`。
输出的整数加倍结果和字符串拼接结果，证明模板能按类型实例化。
模板定义在调用点可见，因此两个实例都能成功编译。

## 易错点
模板定义若只在调用点留下声明，实例化时可能找不到函数体。
不同类型必须支持模板函数实际使用的操作，否则实例化无法通过。
让定义对实例化点可见，并选择两种都支持所需操作的类型。

## 延伸
进一步实现类模板，并用不同类型创建对象。
了解模板定义通常放在头文件中，以便使用点进行实例化。
