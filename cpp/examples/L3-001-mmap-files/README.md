# L3-001-mmap-files

<!-- coverage: pending -->

## 考点
对应 KP-L3-01：用 `mmap` 读取文件，并按页大小向上取整映射长度。
看到正确内容、文件字节数和映射字节数，且空文件安全处理，即说明掌握映射边界与生命周期。

## 易错点
把文件长度直接当作映射长度会忽略页边界；按页大小向上取整，并始终只读文件有效字节。
空文件不能按零长度调用 `mmap`；先判断长度，且在关闭文件前解除非空映射。

## 延伸
将固定内容替换为分块文本扫描，比较映射读取与缓冲区读取的吞吐。
继续处理映射文件被外部截断的风险，并限定映射区间的访问范围。
