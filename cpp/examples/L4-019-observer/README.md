## 考点

对应 KP-L4-19：主题状态变化时通知所有已注册观察者，主题不依赖观察者的具体类型。

可观察判据：两个观察者注册后主题变更触发两次回调，按注册顺序输出固定文本；取消注册后只触发一次。

## 为什么这样写

代码位置（`main.cpp`）：第 8–26 行定义抽象观察者和两种回调，第 30–58 行注册、取消及快照通知，第 63–72 行触发两轮通知。

`Subject` 按注册顺序保存 `shared_ptr<Observer>`，版本变化时只通过抽象接口调用 `update()`。两个具体观察者实现不同回调，`main()` 注册后改版本、取消 cache 再改版本。空指针、重复注册和取消不存在的注册均显式抛出异常。

通知遍历注册列表的共享指针快照：回调期间即使改动注册，当前轮仍按开始时名单完成，下一轮才应用变更，避免迭代器失效和对象悬垂。删掉虚函数通知，日志会消失；删掉 `unsubscribe()` 的实际移除，第二轮通知会多出 `cache invalidated: 2`，不再只有第三行 display 回调。
