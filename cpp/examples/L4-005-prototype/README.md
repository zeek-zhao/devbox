# L4-005-prototype


## 考点

对应 KP-L4-05：通过克隆已有实例创建新对象，避免重复执行昂贵构造。

可观察判据：基类声明 `clone()` 返回 `unique_ptr`，拷贝后修改副本字段不影响原对象；构造计数只增加一次。

## 为什么这样写

`main.cpp` 第 7–12 行声明原型接口，第 17–22 行区分初始化构造和默认拷贝构造，`clone()` 复制已有索引而不重新初始化。
第 24–33 行用按值存储的 `vector<string>` 隔离内部数据，计数器只记录需要初始化预置数据的构造，不计克隆时的拷贝构造。
第 37–43 行通过基类指针克隆、修改副本和读取双方字段。
若改成共享内层容器，`original: cpp` 会变成 `original: clone`；若克隆改为默认构造新索引，最后的构造计数会从 1 变成 2。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh cpp L4-005-prototype
```
