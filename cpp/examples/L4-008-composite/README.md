# L4-008-composite


## 考点

对应 KP-L4-08：把叶子与容器统一成同一接口，递归组合后可整体操作。

可观察判据：叶子与容器实现同一接口，对根节点调用 `render()` 输出按层缩进的全部叶子文本。

## 为什么这样写

`main.cpp` 第 7–11 行的统一接口只声明渲染，不强迫叶子实现无意义的添加子节点方法。
第 13–37 行分别实现叶子和容器；容器持有 `unique_ptr<Node>`，第 29–32 行递归虚派发并增加深度。
第 40–50 行构造三层树，最终只通过根的基类指针调用一次 `render()`。
若取消递归，`beta`、`gamma` 会缺失；若去掉深度递增，第三行 `gamma` 前的六个空格会消失，精确输出即不匹配。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh cpp L4-008-composite
```
