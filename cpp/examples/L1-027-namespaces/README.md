# L1-027-namespaces


## 考点
对应 KP-L1-27：限定调用能无歧义地区分不同命名空间中的同名函数。
`using` 引入单个函数后可直接调用；局部变量也会遮蔽 `using` 引入的同名名称。

## 易错点
不限定同名名称会产生查找歧义或意外绑定；优先写清命名空间限定名。
局部变量会遮蔽已引入的同名名称，避免在同一作用域复用容易混淆的标识符。

## 延伸
可把模块的类型与函数分别放入命名空间，并练习嵌套命名空间和别名。
在头文件中避免 `using namespace`，防止名称污染包含者的作用域。
