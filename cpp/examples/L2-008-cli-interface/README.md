<!-- coverage: pending -->

## 考点
对应 KP-L2-08：有效查询成功，缺少参数和非法选项均给出可判定提示及非零状态，帮助请求成功。
看到脚本逐项显示响应和对应退出码，就说明命令行输入与错误路径可被区分。

## 易错点
直接把用户字符串转换成数字或默认接受未知选项，会误收非法输入。
先校验选项和必需参数；脚本用条件分支接住预期的非零状态，不让它终止整组用例。

## 延伸
可以为查询参数增加数值范围、重复选项和互斥选项校验。
再把参数解析与查询执行分开，分别测试输入规则和业务逻辑。
