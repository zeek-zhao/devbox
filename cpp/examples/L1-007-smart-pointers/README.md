# L1-007-smart-pointers


## 考点
对应 KP-L1-07：`unique_ptr` 独占管理资源，共享所有权形成环时节点计数都为 2。
将环的一条强引用改为 `weak_ptr` 后，对应计数降为 1。
作用域结束后两个节点都析构，说明弱引用不延长对象生命周期。

## 易错点
两个 `shared_ptr` 互相持有会让引用计数无法归零，析构不会发生。
仅在作用域结束时释放外部指针不能打破这个强引用环。
用 `weak_ptr` 表示不拥有对象的反向关系，需要访问时再通过 `lock()` 获取强引用。

## 延伸
练习以 `unique_ptr` 表达独占所有权，并比较其与共享所有权的生命周期。
在异步回调中尝试用弱引用避免对象被不必要地延长生命周期。
