# L1-006-perfect-forwarding


## 考点
对应 KP-L1-06：包装函数用 `std::forward` 保留实参的值类别。
看到左值产生一次拷贝、右值产生一次移动，即可验证转发行为。
计数由拷贝构造和移动构造记录，避免把 `std::move` 误认为实际移动。

## 易错点
把具名的转发引用直接传递会变成左值，右值也可能因此被拷贝。
`std::forward<T>` 依赖模板推导出的 `T`，不能对所有参数盲目替换为 `std::move`。
使用转发引用并按原推导类型转发，可保留调用者传入的值类别。

## 延伸
继续观察带 `const` 限定的左值如何影响重载和拷贝构造。
可将相同的转发包装应用于可变参数函数模板。
