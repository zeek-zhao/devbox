# L4-011-flyweight


## 考点

对应 KP-L4-11：共享内在状态、外部状态由调用方传入，避免重复创建大量同质对象。

可观察判据：工厂对相同 key 返回同一实例地址，不同 key 返回不同地址；创建计数等于不同 key 数。

## 为什么这样写

`main.cpp` 第 7–16 行的享元只保存不可变词元，位置是每次 `render()` 的参数。
第 20–29 行的工厂先查缓存，仅首次遇到 key 才创建对象并增加计数；缓存和调用方持有只读共享指针。
第 39–50 行实际取用两个相同 key 和一个不同 key，比较真实地址，打印真实创建计数，并在不同位置复用同一词元。
若去掉缓存，第一行会变成 `false`、创建数会变成 3；若改成在首次创建时固定保存位置而忽略后续位置参数，第五行 `cpp@8` 会错误地变成 `cpp@1`。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh cpp L4-011-flyweight
```
