## 考点

对应 KP-L4-10：用单一入口封装子系统多个步骤，调用方不感知内部协作。

可观察判据：外观类依次调用三个子系统，`start()` 输出按固定顺序的三行日志。

## 为什么这样写

`main.cpp` 第 7–34 行分别实现解析、索引与渲染子系统，各自在完成自己的步骤时输出日志。
第 38–41 行的外观只负责按顺序委托，解析所得词列表传给索引，索引条目数再传给渲染，不在外观直接打印成功结论。
第 50–53 行的调用方只知道外观入口。
若跳过索引子系统，第二行 `index: 3 entries` 会缺失；若改动调用顺序，三行日志顺序会变化。修改输入词数也会贯穿三步改变计数。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh cpp L4-010-facade
```
