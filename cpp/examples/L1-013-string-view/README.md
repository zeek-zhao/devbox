# L1-013-string-view


## 考点
对应 KP-L1-13：区分拥有字符的 `std::string` 与不拥有字符的 `std::string_view`。
修改仍然存活的源字符串后视图显示新字符，而由视图复制构造的独立字符串保持原内容。

## 易错点
视图不延长底层字符的生命周期；源字符串销毁后继续使用视图会悬垂并产生未定义行为。
需要跨越源对象生命周期保存文本时，复制到 `std::string`，并避免从临时字符串留下视图。

## 延伸
练习用 `string_view` 接收只读文本参数，避免不必要的字符串分配与复制。
进一步检查字符串修改、扩容及子视图边界对视图有效性的影响。
