# L1-004-raii

<!-- coverage: pending -->

## 考点
对应 KP-L1-04：资源由 RAII 对象持有，作用域退出时自动释放。
正常离开作用域和抛出异常后都出现对应释放标记，说明两条路径均清理资源。

## 易错点
只在正常路径手动释放，异常跳出时会泄漏资源。
将获取和释放绑定到自动析构的所有者，避免依赖每个控制流分支手动清理。

## 延伸
用 `std::unique_ptr` 自定义删除器封装文件句柄，并验证错误路径自动关闭文件。
了解锁守卫如何用相同的作用域机制在异常时释放互斥锁。
