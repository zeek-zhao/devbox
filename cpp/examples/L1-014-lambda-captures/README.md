# L1-014-lambda-captures

<!-- coverage: pending -->

## 考点
对应 KP-L1-14：选择 Lambda 的值捕获或引用捕获，并理解闭包对象与捕获对象的关系。
外部变量改值后，值捕获仍读到原值、引用捕获读到新值，说明两种捕获的可观察差异。

## 易错点
引用捕获不会延长局部变量生命周期；闭包若比被引用对象活得久，再调用会访问悬垂引用。
让闭包在对象仍存活时调用，或在需要延迟执行时按值捕获，避免越过作用域边界。

## 延伸
比较可变 Lambda 对值捕获副本的修改行为与对外部引用对象的修改行为。
结合算法谓词与异步任务，明确闭包何时调用以及被捕获对象的生命周期。
