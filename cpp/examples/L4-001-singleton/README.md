# L4-001-singleton

<!-- coverage: pending -->

## 考点

对应 KP-L4-01：同一类型全局只存在一个实例，所有取用点看到同一份状态。

可观察判据：用函数内 `static` 局部变量延迟构造并删除拷贝构造与赋值；两次取实例地址相等，第二次写入的计数在第三次读取时为新值。

## 为什么这样写

`main.cpp` 第 6–12 行用函数内静态对象提供唯一入口并禁止复制，第 22–23 行在编译期验证不可拷贝。
第 26–31 行实际取用三次：比较前两次地址，通过第二个引用写入 7，再通过第三个引用读取。
若每次取用改成独立实例，`same instance: true` 会变成 `false`，`count: 7` 会变成初始值 0；结论不是硬编码。

TAG=latest bash scripts/run-example.sh cpp L4-001-singleton
