# L3-006-ffi-abi


## 考点
对应 KP-L3-06：C 文件提供稳定的 `extern "C"` 接口，C++ 调用并检查返回码。
看到 C 分配的字符串由 C++ 显式 `free`，以及调用方识别的错误码，即说明 ABI 与所有权清楚。

## 易错点
跨边界传递 STL 类型或 C++ 异常会依赖运行时 ABI；接口只传 C 整数和指针。
分配释放器不匹配会导致未定义行为；由 C 的 `malloc` 分配，并由兼容的 `free` 释放。

## 延伸
为接口添加不透明句柄，明确创建、销毁和每种错误码的约定。
检查导出符号与调用约定，并在多个编译器构建的 C/C++ 模块间验证兼容性。
