# L2-007-env-config —— 通过环境变量切换渲染配置

## 考点

- 在启动进程时从 `process.env.APP_MODE` 读取配置。
- 两次独立运行同一程序，分别观察 `a`、`b` 对渲染内容的影响。

## 为什么这么写

模式通过 `APP_MODE=a node ...` 注入，而非修改源文件中的常量，模拟部署环境在进程启动时提供配置的方式。

## 易错点

- 环境变量是字符串；本例对未支持的值显式报错。
- 必须启动两个进程验证两个分支，不能在代码中伪造第二个输出。

## 运行

```bash
TAG=latest scripts/run-example.sh vue L2-007-env-config
```
