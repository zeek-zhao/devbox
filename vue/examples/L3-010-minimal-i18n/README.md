# L3-010-minimal-i18n —— 双语词典与重复占位符

## 考点

- 按语言和键查词典，同一组件分别 SSR 英文和中文。
- 全局正则替换两次出现的 {name}，不是只替换首个。
- 缺词条或参数明确报错；替换值中的 $& 保持字面含义。

## 为什么这么写

重复占位符可以直接暴露漏写 g 的问题。使用 replace 回调而不是替换字符串，
避免用户名字里的 $& 被当作正则替换指令。翻译作为 h 的文本子节点，
由 SSR 转义，不使用 innerHTML。中文词典是考点要求，因此保留 Unicode。

## 易错点

- 非全局 replace 会留下第二个 {name}。
- 缺少参数时默默返回 undefined，会产生看似成功的坏译文。
- 拼 HTML 字符串会绕过 Vue 文本转义。

## 运行

```bash
TAG=latest scripts/run-example.sh vue L3-010-minimal-i18n
```
