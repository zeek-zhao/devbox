# L2-004-unit-test-harness —— 手写最小断言测试框架

## 考点

- 用严格相等断言检测实际值和期望值。
- 统计成功断言数，并在首个失败时以非零状态退出。

## 为什么这么写

测试框架自身用少量代码实现，不依赖 `node:test` 的版本行为；四条断言覆盖不同值类型，成功数来自实际执行计数。

## 易错点

- 失败不能只打印错误后继续，否则最终计数会给出成功形状的输出。
- 用 `!==` 比较，避免松散相等把类型错误当成通过。

## 运行

```bash
TAG=latest scripts/run-example.sh vue L2-004-unit-test-harness
```
