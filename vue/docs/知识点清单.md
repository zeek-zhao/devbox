## 本轨道不覆盖什么

- **不测打包器和 bundle 产物**：没有 Vite、Webpack 或基于打包输出的用例；SFC 用 `@vue/compiler-sfc` 直接编译检查，SSR 直接输出 HTML。
- **不测真实浏览器 DOM、挂载、hydration 执行或端到端交互**：用例运行在 Node SSR 环境；`L3-003-hydration-mismatch` 只模拟并比较两端 SSR HTML，不能代替浏览器水合。
- **不测 Vue Devtools**：当前用例没有浏览器扩展或 Devtools 环境。
- **不测 Vue Router 路由行为**：清单中没有路由器、导航或路由组件用例。
- **不测生产服务器部署与浏览器资源加载**：验证边界是 Node 中的组件 API、SFC 编译接口及 SSR 输出，而非完整客户端部署链路。
