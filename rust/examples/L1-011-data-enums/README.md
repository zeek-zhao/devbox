# L1-011-data-enums

<!-- coverage: pending -->

## 考点
对应 KP-RS-L1-11：用带数据枚举表达互斥状态及其专属数据。
看到不同变体分别携带并输出各自字段，说明每种状态的数据形状明确。

## 易错点
会把互斥状态拆成可能互相矛盾的多个字段；使用一个带数据枚举保证每次只存在一种状态。
根据当前状态选一个变体构造，并只给它提供对应载荷，避免状态组合失配。

## 延伸
为索引任务定义排队、运行和完成等变体，并为每种状态携带所需信息。
再用方法封装状态转换，确保转换后进入明确的状态。
