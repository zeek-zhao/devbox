# L1-024-box-ownership

<!-- coverage: pending -->

## 考点
对应 KP-RS-L1-24：`Box<T>` 持有堆上数据的唯一所有权，解引用可读写，间接字段使递归类型大小有限。
看到装箱值从 7 改为 8、移动交还后为 10、递归节点按值消费得到 `[2, 5]`，说明掌握装箱与所有权转移。

## 易错点
误以为 `Box` 自动共享或消除所有权规则，会在移动后继续使用旧绑定时编译失败。
本例移动后只使用交还的绑定，递归遍历逐步接管下一节点；需要共享时另选共享指针。

## 延伸
在毕业项目中用 `Box` 连接树形查询计划的子节点，保持每个节点有明确所有者。
扩展按值遍历以消费整棵计划树，对比借用遍历保留树的使用场景。
