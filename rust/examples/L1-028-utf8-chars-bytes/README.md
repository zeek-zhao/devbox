# L1-028-utf8-chars-bytes

<!-- coverage: pending -->

## 考点
对应 KP-RS-L1-28：`chars()` 遍历 Unicode 标量值，`bytes()` 遍历 UTF-8 编码字节，`len()` 统计字节。
看到 `A中🦀` 的标量数为 3、字节数为 8，且逐项序列精确匹配，说明没有把两种计量单位混淆。

## 易错点
把字节数当作字符数，会使文本长度与展示不一致，因为非 ASCII 标量可占多个字节。
按标量操作用 `chars`，按编码处理用 `bytes`；组合文本 `e` 加重音有两个标量，不等于两个展示字形。

## 延伸
在毕业项目中分别记录文本标量统计与文件字节偏移，字段名称明确标注单位。
增加不同语言的固定文本，验证标量计数并不是用户可见字形计数，不用标准库伪造字形分段。
