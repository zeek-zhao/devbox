# L3-004-c-abi-ffi


## 考点
对应 KP-RS-L3-04：Rust 通过 `extern "C"` 调用独立编译并显式链接的 C 函数。
看到有效切片得到正确字节和、空输入在安全封装处被拒绝，说明 FFI 契约可见。

## 易错点
会解引用空指针或错误长度而触发未定义行为，因为编译器无法检查外部契约；在安全封装中验证指针、长度和所有权约定。
只把有效切片传入裸指针接口，并保证 C 端仅在约定长度内读取。

## 延伸
为 C 接口增加错误码和长度边界测试，明确跨语言的整数类型映射。
进一步检查谁分配和释放缓冲区，避免跨 ABI 错误转移所有权。
