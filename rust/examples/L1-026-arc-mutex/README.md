# L1-026-arc-mutex

<!-- coverage: pending -->

## 考点
对应 KP-RS-L1-26：`Arc` 共享同一计数器，`Mutex` 守卫保护每次写入，线程结束后统一读取。
看到 4 个线程各加 25 次得到 100、句柄数回到 1，说明共享状态可跨线程传递且更新没有丢失。

## 易错点
持锁时再次 `lock` 同一互斥量可能死锁，忽略锁中毒结果也会漏掉错误。
本例用 `try_lock` 安全观察阻塞，保持短锁作用域，显式传播中毒与线程错误，所有线程 `join` 后才输出统计。

## 延伸
在毕业项目的并行扫描中只在合并统计时持锁，不把文本解析放进临界区。
为锁中毒设计顶层错误报告策略，不把错误静默当成零计数。
