# L3-003-scoped-thread-channel

<!-- coverage: pending -->

## 考点
对应 KP-RS-L3-03：作用域线程借用任务切片，通过通道收集结果并用互斥量汇总。
看到三个固定任务结果按编号排序且共享总和正确，说明线程收尾与同步均有效。

## 易错点
会让线程借用的数据先于线程结束而失效，或按调度顺序比较结果；使用作用域线程等待收尾、同步共享状态并排序汇总。
由作用域结束等待所有工作完成，再由单一线程按稳定任务编号打印。

## 延伸
为任务切片加入边界输入，并比较有界通道与无界通道的背压行为。
将互斥状态替换为分片统计，评估汇总阶段的同步成本。
