# L1-018-lazy-iterators


## 考点
对应 KP-RS-L1-18：区分创建迭代器适配器与消费迭代器的操作。
看到创建 `map` 后闭包计数仍为零，消费后计数增加且结果正确，说明理解了惰性求值。

## 易错点
会只构造适配器却期待闭包执行，因为适配器惰性求值；调用 `collect`、`fold` 等消费操作触发遍历。
在需要观察或使用转换结果时显式消费迭代器，而不是只保存适配器。

## 延伸
把延迟转换用于按需生成查询候选，并仅在最终消费时执行计算。
对比 `collect` 和 `fold` 等消费操作在结果用途上的差异。
