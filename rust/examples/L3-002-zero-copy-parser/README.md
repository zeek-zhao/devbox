# L3-002-zero-copy-parser


## 考点
对应 KP-RS-L3-02：解析结果通过生命周期标注借用调用方输入切片。
看到字段切片与输入字段起始地址相同且内容正确，说明解析未复制字段。

## 易错点
会返回指向临时缓冲区的切片而编译失败，或让调用者在借用期间修改输入；由调用方持有缓冲区并遵守共享借用约束。
解析结果存活期间输入保持共享借用，解析器不创建临时字段缓冲区。

## 延伸
为解析结果增加多个借用字段，并覆盖截断与非法 UTF-8 输入。
探索用 `&str` 表示已验证文本字段，同时让输入缓冲区继续由调用方管理。
