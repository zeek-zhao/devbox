# L1-023-move-closures


## 考点
对应 KP-RS-L1-23：`move` 捕获整数副本、拥有型 `String` 或显式引用，取决于绑定类型。
看到闭包整数仍为 3、外层改为 8，字符串从闭包交还，而捕获引用时外层仍可读，说明能区分复制与移动。

## 易错点
假定 `move` 必然复制捕获值，会在外层再次使用已移动的 `String` 时编译失败。
检查类型是否为 `Copy`；需要共享时先显式借用，本例在借用结束后才修改源字符串。

## 延伸
在毕业项目的延迟任务中移动拥有型查询参数，保证任务执行时数据仍然有效。
短期只读任务可捕获引用，但不能让任务比查询参数活得更久。
