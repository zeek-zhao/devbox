# L3-001-binary-format

<!-- coverage: pending -->

## 考点
对应 KP-RS-L3-01：逐字段编码版本和 little-endian 整数，并校验解码边界。
看到固定字节序列可往返还原字段、截断记录被拒绝，说明格式不依赖内存布局。

## 易错点
会把内存结构直接写盘而依赖平台布局或字节序；逐字段编码并校验长度、版本和取值范围。
先验证切片长度再读取字节，避免截断输入触发越界访问。

## 延伸
为记录增加校验和与明确的字段兼容策略。
对非法版本、越界值和每一种截断位置补充解析测试。
