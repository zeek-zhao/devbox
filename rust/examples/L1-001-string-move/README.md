# L1-001-string-move

<!-- coverage: pending -->

## 考点
对应 KP-RS-L1-01：`String` 传值会移动所有权，`&str` 参数只借用。
看到借用后调用方仍打印 `rust`，传值后仅接收方追加并打印 `rust index`，说明能区分所有者。
移动后的原绑定不再访问；若再次使用它，借用检查会拒绝，而不是产生运行期错误。

## 易错点
会因传值后继续用原变量而编译失败，因为所有权已经转移。
需要继续访问时传 `&str`；确实需要独立值时才克隆，本例不靠克隆绕过移动。

## 延伸
为查询词和文档内容划分所有权边界：只读查询函数借用，消费任务的函数接收拥有型值。
练习把消费函数改成返回 `String`，由调用方接收返回值后重新取得所有权。
