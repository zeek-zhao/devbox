# L1-005-borrow-scope

<!-- coverage: pending -->

## 考点
对应 KP-RS-L1-05：非词法生命周期使借用在最后一次实际使用后结束。
看到同一花括号内先打印只读切片 `query`，随后源缓冲区成功追加并输出 `query ready`，说明掌握借用终点。
没有额外内层作用域，也没有克隆或显式销毁引用。

## 易错点
会认为引用必须活到花括号末尾，造成不必要的借用冲突和作用域拆分。
按最后一次实际使用安排读写顺序；若追加后再次读取旧引用，借用仍活跃，编译器就会拒绝修改。

## 延伸
解析输入缓冲区后先完成所有切片读取，再复用缓冲区存放下一阶段内容。
在查询解析流程中找出最后一个切片消费者，避免仅为结束借用增加额外文本副本。
