# L1-031-drop-order


## 考点
对应 KP-RS-L1-31：观察局部值离开作用域时的 `Drop` 顺序。
看到先创建的值最后清理（`second` 后 `first`），说明掌握了逆序销毁。

## 易错点
显式调用 `drop(value)` 会移动该值，之后再使用会触发移动诊断。
让作用域负责资源清理；若提前销毁，就不要再使用该值。

## 延伸
用带标记的守卫比较嵌套作用域中的清理顺序。
再观察文件句柄或锁守卫在作用域结束时释放的时机。
