# L1-010-custom-errors


## 考点
对应 KP-RS-L1-10：`IndexError` 组合数字解析与 UTF-8 解码两种来源，分别实现 `From`。
看到合法记录输出编号，两种失败输出稳定的领域类别，说明 `?` 已自动转换为相应错误变体。
两次 `source preserved: true` 由底层错误类型检查得到，证明来源没有被转换成纯文本丢失。

## 易错点
会在每个调用点手工映射错误或丢失来源，因为转换路径未定义。
为底层错误实现合适的 `From` 并保留上下文；本例用变体区分文档编号和文本，通过 `Error::source` 暴露原错误。

## 延伸
在索引构建错误分层中让领域错误保存底层载荷，边界统一匹配类别。
新增失败来源时同时补充转换、展示和来源链，避免调用方重复编写错误映射。
