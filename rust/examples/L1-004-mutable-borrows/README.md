# L1-004-mutable-borrows


## 考点
对应 KP-RS-L1-04：`&mut String` 能修改源值，但活跃写者必须独占访问。
看到写者追加 `doc2`，结束写借用后的读者看到更新，再由下一写者追加 `doc3`，说明掌握读写分阶段。
各借用作用域不重叠；若保留写者再同时使用其他借用，编译器会拒绝。

## 易错点
会同时保留活跃的可变和不可变引用，因为这破坏别名安全，无法通过借用检查。
缩短借用作用域或分开读写阶段；不要在写者仍需使用时另建读者或第二个写者。

## 延伸
将索引构建过程中的更新接口设计为接收 `&mut`，调用方继续拥有索引。
把更新和展示放在相邻但不重叠的阶段，检查每阶段只保留必需引用。
