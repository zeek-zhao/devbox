# L1-006-return-lifetimes

<!-- coverage: pending -->

## 考点
对应 KP-RS-L1-06：`shorter<'a>` 用输入输出的 `'a` 关联返回切片与两个可能来源。
看到交换输入顺序后仍选出 `rust`，且结果只在两个来源都存活的内层作用域使用，说明掌握返回引用关系。
两个输入有歧义，删掉这些关联不能靠省略规则推断返回来源；本例只运行合法版本。

## 易错点
会把标注误当成延长数据寿命的操作，试图返回或保留指向已失效对象的引用。
确保返回引用所指对象仍存活；本例不把选中内层 `query` 的引用带出作用域。

## 延伸
在查询结果引用原始文本片段时，让接口明确结果与原始文档的生命周期关系。
比较“只返回第一个输入”和“可能返回任一输入”的签名，分析第二个输入是否需要共享生命周期。
