# L1-003-shared-borrows


## 考点
对应 KP-RS-L1-03：同一 `String` 的两个 `&str` 只读借用可以同时存活，不转移所有权。
看到两个读者和原所有者均读出 `rust`、比较为 `true`，说明理解了共享只读访问。
读者所在作用域结束后，所有者才追加并打印 `rust docs`。

## 易错点
会在只读借用仍存活且后续还要使用时修改源值，因为读者可能观察到变化，编译器会拒绝。
先结束借用作用域再修改；本例用内层作用域明确分开只读访问和所有者修改。

## 延伸
给查询输入安排多个只读消费者，传递切片而不复制文本。
检查查询校验和查询展示两个接口是否只需 `&str`，避免不必要地取得所有权。
