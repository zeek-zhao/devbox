# L1-012-exhaustive-match


## 考点
对应 KP-RS-L1-12：对枚举进行穷尽 `match`，并在分支中绑定数据。
看到每种状态都由独立分支处理且数据被输出，说明分派覆盖完整。

## 易错点
会用宽泛通配分支掩盖新增状态，因为新情况仍能编译但未被专门处理；对关键状态显式列出分支。
新增变体时逐一更新关键 `match`，让编译器指出遗漏。

## 延伸
为查询结果增加“部分命中”状态，并为其载荷编写专属分支。
将穷尽匹配用于索引查询结果分派，明确区分空结果与错误状态。
