# L3-005-std-benchmark


## 考点
对应 KP-RS-L3-05：使用标准库计时包围固定工作量，并以操作计数和校验值验收。
看到固定的 1000 次操作与校验值，而期望输出没有墙钟耗时，说明基准结果可重复。

## 易错点
会把单次墙钟时间写入期望输出而导致结果不稳定；用校验值和操作计数断言正确工作量，时间仅作非断言诊断。
计时值仅保留作本地诊断，不参与 stdout 或成功条件。

## 延伸
比较不同实现时固定输入规模并核对相同校验值。
重复测量并在本地分析耗时分布，但不要将单次时间作为 CI 断言。
