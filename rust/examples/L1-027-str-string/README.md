# L1-027-str-string


## 考点
对应 KP-RS-L1-27：`&str` 是借用型字符串切片，`String` 拥有数据并可增长。
看到同一接口接受字面量和 `String` 借用、原值仍可追加、函数返回的拥有型值仍可读，说明区分了两种接口。

## 易错点
返回指向临时 `String` 的切片会产生生命周期错误，因为函数退出后临时数据不再存在。
借用返回值来自调用方持有的数据；函数内部生成新文本时返回拥有型 `String`，不返回局部值的引用。

## 延伸
在毕业项目中用 `&str` 接收查询词，让字面量与文件内容借用共用同一只读接口。
需要拼接或保存查询文本时返回 `String`，并由调用方决定拥有型结果的存活范围。
