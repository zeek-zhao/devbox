# L1-016-trait-default-methods

<!-- coverage: pending -->

## 考点
对应 KP-RS-L1-16：trait 默认方法提供复用行为，具体类型也可覆盖它。
看到仅实现必需方法的类型走默认路径、覆盖方法的类型输出不同结果，说明理解了动态选择。

## 易错点
会把默认方法当作所有类型的固定行为，忽略覆盖实现；调用行为由具体实现决定，需测试默认和覆盖两条路径。
为默认实现和覆盖实现各构造一个类型，并分别调用同一方法核对结果。

## 延伸
为不同文档来源提供默认摘要，同时允许特定来源替换摘要策略。
扩展 trait 时保留合理默认行为，减少既有实现的改动。
