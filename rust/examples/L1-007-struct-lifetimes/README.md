# L1-007-struct-lifetimes


## 考点
对应 KP-RS-L1-07：`DocumentView<'a>` 的引用字段依赖外部文本，结构体不拥有这些文本。
看到记录打印标题和正文，记录作用域结束后两个文本所有者仍可打印，说明掌握视图与来源的寿命边界。
结构体仅在来源存活期间使用；让记录引用已离开作用域的局部文本会被编译器拒绝。

## 易错点
会遗漏结构体生命周期参数或让引用指向过期局部值，因为引用字段必须声明并满足来源寿命。
约束引用来源寿命，如本例由外层绑定提供数据；需独立持有文本时将拥有型数据放在结构体内。

## 延伸
在零拷贝文档记录中用切片字段借用文档内容，让文档存储比记录存活更久。
比较借用型记录和拥有型记录的使用范围，明确缓存记录时应由谁保留原始文本。
