### 探针 3：KP-RS-L3-02

<!-- probe:lang=rust -->

```rust
struct Record<'a> { name: &'a [u8] }
fn parse(input: &[u8]) -> Record<'_> {
    Record { name: &input[0..2] }
}
fn main() {
    let bytes = b"rust";
    let record = parse(bytes);
    println!("{}", std::str::from_utf8(record.name).unwrap());
}
```

**实测输出**

```text
ru
```
