# Rust 知识点清单

## 1. 怎么使用

每个 KP 对应一个用例，建议用例 ID 在本级别内从 `001` 连续编号。L1 是单文件可验证的语言能力，L2 是 Cargo 工程与质量门禁，L3 是需要额外技术设计的专题。判据必须能由编译结果、运行输出或命令退出状态复核。本清单只使用 Rust 标准库和固定工具链；不要求下载任何依赖。

## 5. 明确不覆盖的

| 内容 | 为什么不覆盖 |
|---|---|
| 需要下载的第三方 crate | 课程容器没有注册表缓存且无外网，依赖下载无法完成，后续用例不能可靠构建。 |
| 需要额外执行框架的异步任务 | 相关依赖无法从离线容器获取；本轮并发能力使用标准库线程与同步原语验证。 |
| 过程宏开发与依赖宏生态 | 过程宏须额外构建 crate 且通常依赖生态包，超出固定离线工具链约束。 |
| 网络请求和远程服务集成 | 容器外网不可用，服务端状态与响应也不能成为稳定的期望输出。 |
| 依赖机器负载的精确性能阈值 | 墙钟受调度、负载和硬件影响，无法作为跨运行机器可复核的固定断言。 |
| 操作系统专属 API | 不同目标平台的接口、权限和错误码不一致，当前用例要求标准工具链可重复验收。 |
| GUI 与图形窗口 | 与毕业项目的文本索引目标无关，也不属于本轮 Rust 语言与工具链核心验收范围。 |
