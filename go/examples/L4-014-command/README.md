## 考点

对应 KP-GO-L4-14：把请求封装成对象，从而可参数化、排队、撤销。

可观察判据：命令接口含 `Execute`/`Undo`，执行两次再撤销一次后状态为固定值。

## 为什么这样写

`main.go` 第 8–27 行将接收者抽象为接口，把增量和接收者封装进命令，
`Undo` 通过相反增量撤销；命令不依赖 `Counter` 具体类型。
第 29–51 行的调用器只保存命令接口，按队列执行并从历史末尾撤销，
历史为空时显式返回错误。第 57–64 行排队两个命令，真实执行加 5、加 3，
再撤销第二个命令，打印接收者当前值 8 和 5。
若拆掉历史记录，撤销会报错；若去掉逆操作，`after undo: 5` 会变成
`after undo: 8`，若错误撤销第一个命令则会变成 3。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh go L4-014-command
```
