# L2-012-test-exit-status


## 考点
对应 KP-GO-L2-12：测试断言失败时 `go test` 和调用它的严格脚本都应非零退出。
看到失败状态被两层门禁检测到，且本用例自身成功结束，说明状态传播已验证。

## 易错点
脚本吞掉测试退出码会让 CI 假绿，因为后续成功命令可能覆盖失败结果。
启用 `set -euo pipefail`，直接运行 `go test`，并用严格脚本验证非零状态确实向上传播。

## 延伸
把测试门禁接入持续集成，并为失败测试保留日志供排查。
再验证测试通过时门禁返回零，确保成功与失败两条路径都被覆盖。
