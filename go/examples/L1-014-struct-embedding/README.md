# L1-014-struct-embedding


## 考点
对应 KP-GO-L1-14：验证嵌入字段的方法提升、同名遮蔽与显式限定调用。
看到外层调用返回外层结果，而字段路径仍能调用内层方法，说明掌握了提升规则。

## 易错点
嵌入只组合字段与方法，并不建立继承关系；同名外层方法会遮蔽提升方法。
需要内层行为时显式写出嵌入字段路径。

## 延伸
将计数能力嵌入索引器，并明确区分索引器自身与统计字段的操作。
为嵌入字段和外层类型添加同名方法，观察选择规则。
