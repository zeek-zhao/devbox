# L3-006-tcp-echo


## 考点
对应 KP-GO-L3-06：在回环地址上建立 TCP listener 并原样回写客户端数据。
客户端收到完全相同的固定字节且 server 完成握手退出，说明本机 Echo 生命周期正常。
监听端口由内核分配，但输出不暴露端口号。

## 易错点
监听通配地址或依赖公网使测试受环境影响；绑定回环地址、设置有界超时并显式关闭 listener 与连接。
端口使用 `127.0.0.1:0` 动态分配；用 channel 等待 server 结束，不用固定延时猜测。

## 延伸
为 Echo 增加长度前缀协议，并测试短读、超时和客户端提前关闭。
将本机协议验证扩展到索引服务的请求与响应边界。
