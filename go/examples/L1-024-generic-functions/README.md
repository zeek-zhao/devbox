# L1-024-generic-functions


## 考点
对应 KP-GO-L1-24：同一个带类型参数的函数处理 []int 与 []string。
看到两种输入均得到倒序副本、原输入不变，且显式类型的空输入长度为 0，即掌握通用实现。

## 易错点
类型参数必须由调用推断或显式提供，只有 nil 的调用无法推断元素类型。
把与类型无关的逻辑抽成单一函数；有具体切片时推断，无类型信息时写 reversed[int](nil)。

## 延伸
把该函数用于查询结果集合的顺序调整，保留调用方的元素类型。
增加空集合与单元素集合的断言，复用同一泛型实现而非复制不同类型的函数。
