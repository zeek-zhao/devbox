# L2-002-gofmt-vet


## 考点
对应 KP-GO-L2-02：把 gofmt -l 与 go vet 放在 Go 测试之前作为质量门禁。
看到格式检查先发现未格式化源码、修正后列表为空，且 vet 与测试通过，说明掌握了门禁顺序。

## 易错点
gofmt 只调整格式而非逻辑，vet 也不替代测试。
因此格式化与静态检查都要在 go test 前执行，并仍需运行测试验证行为。

## 延伸
将格式检查、静态分析和测试按此顺序接入持续集成的 Go 质量任务。
可继续为门禁增加显式的失败提示，但不要把检查输出中的环境路径写进结果。
