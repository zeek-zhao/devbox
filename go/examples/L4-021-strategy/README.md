# L4-021-strategy


## 考点

对应 KP-GO-L4-21：把可互换算法封装成对象，运行时替换而不改调用方。

可观察判据：策略接口两个实现，切换后同一输入输出不同固定结果。

## 为什么这样写

`main.go` 第 8–26 行定义策略接口及升序、降序两个实现，算法接收通用整数切片，
复制后排序，不绑定调用方的具体结构体。
第 28–31 行上下文只持有策略接口并提供替换入口。
第 34–39 行对相同输入、相同上下文调用两次，中间实际替换策略。
若拆掉第 30 行的替换，`descending: [3 2 1]` 会变成 `descending: [1 2 3]`；
若排序前不复制，`input unchanged: [3 1 2]` 会变成 `[3 2 1]`。
输出打印的是算法结果和原输入，而非写死的比较结论。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh go L4-021-strategy
```
