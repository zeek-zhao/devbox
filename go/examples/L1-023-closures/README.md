## 考点
对应 KP-GO-L1-23：闭包保留词法变量，创建函数返回后仍可读取。
看到 live 两次返回修改后的 8、snapshot 两次保持 3，即掌握引用捕获与局部快照的差异。

## 易错点
延迟执行闭包可能读到后来变化的变量，创建闭包并不会自动冻结当时的值。
需要固定快照时显式传参或先复制局部值；本例复制 threshold 后不再修改 snapshot。

## 延伸
为查询谓词捕获阈值，比较实时配置与固定查询配置两种策略。
让谓词工厂返回后再执行过滤，断言快照不受工厂内后续赋值影响。
