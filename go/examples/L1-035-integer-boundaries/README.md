# L1-035-integer-boundaries

<!-- coverage: pending -->

## 考点
对应 KP-GO-L1-35，int8 的上下界在转换前检查，边界值接受而越界值拒绝。
无符号减法先比较大小，观察安全差值与下溢拒绝结果即可验证边界检查已掌握。

## 易错点
无符号减法可能回绕，窄化转换也可能把越界值变成另一数值；两者都不会自动报错。
先检查上下界再运算或转换，并用最小值、最大值及越界值覆盖边界。

## 延伸
把同类范围校验用于文档偏移量和长度，并在相加前检查最大值边界。
为输入解析增加负数、极大值和空值测试，确保拒绝路径同样明确。
