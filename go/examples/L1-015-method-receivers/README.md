# L1-015-method-receivers


## 考点
对应 KP-GO-L1-15：观察值接收者与指针接收者对值修改的影响。
看到值接收者不改原值、指针接收者经可寻址值调用后改动原值，说明掌握了接收者行为。

## 易错点
自动取址只适用于可寻址值调用，不会改变类型的方法集。
需要满足接口时，显式确认值或指针具有所需的接收者集合。

## 延伸
为可变索引器设计指针接收者方法，为只读查询设计值接收者方法。
比较普通值调用与接口赋值时可用的方法集合。
