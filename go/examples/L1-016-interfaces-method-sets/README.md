# L1-016-interfaces-method-sets


## 考点
对应 KP-GO-L1-16：验证接口隐式满足及值、指针类型的方法集差异。
看到指针实现者通过编译期赋值检查，而值类型的方法集检查为 false，说明掌握了实现边界。

## 易错点
接口满足不需要显式声明，但值类型和指针类型的方法集可能不同。
用编译期赋值检查确认实现者，不要把普通调用时的自动取址当成接口实现。

## 延伸
为 Reader、索引存储和查询接口定义最小方法集，并明确实现类型。
使用编译期赋值检查保护接口与实现之间的契约。
