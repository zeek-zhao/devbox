# L4-017-mediator

<!-- coverage: pending -->

## 考点

对应 KP-GO-L4-17：用中介者集中协调多个同事对象的交互，同事之间不直接引用。

可观察判据：同事持有中介者接口，广播后每个同事收到固定条数消息。

## 为什么这样写

`main.go` 第 5–24 行定义两个接口，中介者保存同事接口并集中广播，
排除发送者本人；新增实现同事接口的类型不需要修改中介者。
第 26–34 行同事只持有中介者接口，发送动作不直接引用其他同事。
第 43–50 行串行注册、发送、打印实际收件箱，三人各发一次后各收到两条。
若拆掉第 34 行的中介转发，各行 `received: 2` 会变成 `received: 0 []`；
若去掉发送者排除则会变成 3 条。切片顺序保证消息和输出确定。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh go L4-017-mediator
```
