# L2-008-flag-cli

<!-- coverage: pending -->

## 考点
对应 KP-GO-L2-08：使用标准库 flag 声明和解析命令行选项。
传入 `-name=devbox` 能得到该配置值，漏传必填值则非零退出并显示用法。
这两个现象说明默认值和非法输入都得到了显式处理。

## 易错点
flag.Parse 只解析定义过的选项，且默认值可能掩盖漏传必填参数。
显式校验必填值，并测试空值输入，确认程序拒绝它而不是静默使用默认值。

## 延伸
为命令增加互斥选项和位置参数，并验证它们组合使用时的行为。
将参数解析与业务逻辑分离，方便对配置校验独立编写单元测试。
