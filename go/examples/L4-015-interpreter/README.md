# L4-015-interpreter

<!-- coverage: pending -->

## 考点

对应 KP-GO-L4-15：用类层次表示文法规则，对输入递归解释求值。

可观察判据：表达式接口含 `Interpret()`，树组合后固定输入输出固定整数。

## 为什么这样写

Go 用接口和组合而非继承表达文法：`main.go` 第 5–19 行定义表达式接口、
数字终结符，以及持有两个表达式接口的加法、乘法非终结符。
第 22–26 行构造 `(2 + 3) * 4` 的树并通过根接口递归求值，没有混入文本解析。
若拆掉第 19 行对子表达式的递归调用，只返回右子树结果，
`(2 + 3) * 4 = 20` 会变成 `(2 + 3) * 4 = 4`；
若加法节点错误执行乘法则结果变成 24，实际结果验证了两层文法组合。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh go L4-015-interpreter
```
