# L1-008-arrays

## 考点
对应 KP-GO-L1-08：将固定长度数组赋值后修改副本，观察原数组保持不变。
原数组内容不变且长度固定，说明掌握数组的值语义。

## 易错点
数组长度属于类型，数组赋值会复制全部元素，而不是共享存储。
需要可变长度集合时使用 slice，不要误把数组赋值当作引用传递。

## 延伸
用固定长度数组表示长度已知的摘要或校验值。
对比相同元素的数组和 slice 在赋值后的变化。
