# L4-010-facade


## 考点

对应 KP-GO-L4-10：用单一入口封装子系统多个步骤，调用方不感知内部协作。

可观察判据：外观结构体持有三个子系统并顺序调用，输出固定顺序。

## 为什么这样写

结构位置：`main.go:8-30` 为三个真实子系统，`main.go:32-46` 为持有它们并串联调用的外观，`main.go:48-51` 为单入口调用方。

`main.go` 的 `SearchFacade` 私有字段持有 `parser`、`indexer`、`renderer` 三个子系统。
`Search()` 的三行依次解析为单词、索引为大写键、渲染成结果，前一步真实返回值作为后一步输入；每个子系统在实际执行时打印自己的阶段与结果。
`main()` 只构造外观并调用 `Search(string) string`，不接触子系统类型。
如果跳过解析，第一行消失；如果跳过索引，第二行消失，后两行的大写键也不再成立。
阶段输出和最终数据同时验证协作，不能靠外观自己打印三条阶段标记冒充子系统调用。
