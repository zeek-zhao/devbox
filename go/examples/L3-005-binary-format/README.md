# L3-005-binary-format

<!-- coverage: pending -->

## 考点
对应 KP-GO-L3-05：按固定版本和大端序逐字段编码二进制记录。
固定整数产生预期字节序列、完整解码还原字段且截断输入被拒绝，说明格式边界明确。

## 易错点
直接写结构体内存会依赖填充与本机字节序；逐字段编码并检查读写长度和版本。
解码前检查完整长度和版本，再按字段偏移读取，不能把截断数据当成部分成功。

## 延伸
为倒排索引磁盘格式加入显式版本迁移，并测试未知版本的拒绝行为。
使用 fuzz test 验证任意截断或损坏字节不会触发越界读取。
