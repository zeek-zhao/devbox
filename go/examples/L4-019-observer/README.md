# L4-019-observer

<!-- coverage: pending -->

## 考点

对应 KP-GO-L4-19：主题状态变化时通知所有已注册观察者，主题不依赖观察者的具体类型。

可观察判据：主题持有观察者接口切片，通知后每个观察者输出固定文本，注销后不再收到。

## 为什么这样写

`main.go` 第 8–34 行定义观察者接口、主题的接口切片和受 Mutex 保护的注册、
注销操作。第 37–46 行修改主题状态、复制观察者快照，释放锁后才通知，
注册关系的修改从下一次通知生效。
第 69–74 行让 alice 在第一次通知回调中注销自己，再发布第二个状态：
真实输出只有 bob 收到 done，收件记录的计数为 alice=1、bob=2。
若拆掉注销，输出会多出 `alice observed: done` 且计数变为 alice=2；
若持锁调用 `Update`，回调中的注销会死锁，无法输出最后的计数。
示例串行发布和回调，观察者记录不并发写入，不依赖 goroutine 调度顺序。

## 怎么跑

```bash
TAG=latest bash scripts/run-example.sh go L4-019-observer
```
