# 清单自检

### 探针 1：KP-GO-L1-09

<!-- probe:lang=go -->

```go
package main
import "fmt"
func main() {
    a := make([]int, 2, 3)
    a[0], a[1] = 1, 2
    b := append(a, 3)
    b[0] = 9
    fmt.Println(a[0], b[0])
    c := append(b, 4)
    c[0] = 7
    fmt.Println(b[0], c[0])
}
```

**实测输出**

```text
9 9
9 7
```

### 探针 2：KP-GO-L2-08

<!-- probe:lang=go -->

```go
package main
import ("flag"; "fmt"; "os")
func main() {
    os.Args = []string{"probe", "-count=3"}
    count := flag.Int("count", 0, "")
    flag.Parse()
    fmt.Println(*count)
}
```

**实测输出**

```text
3
```

### 探针 3：KP-GO-L3-05

<!-- probe:lang=go -->

```go
package main
import ("bytes"; "encoding/binary"; "fmt")
func main() {
    var b bytes.Buffer
    _ = binary.Write(&b, binary.LittleEndian, uint16(0x1234))
    fmt.Printf("% x\n", b.Bytes())
}
```

**实测输出**

```text
34 12
```
