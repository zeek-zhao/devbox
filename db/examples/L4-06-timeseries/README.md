# L4-06-timeseries · 时序数据选型

## 考点
- 同一组三天、两个指标在窄表为 6 行，在宽表为 3 行，展示行数与指标扩展/稀疏性取舍。
- 按日期范围查询分区表，输出计划实际扫描的分区名，证明分区裁剪。
- 数据和日期边界固定，计数与计划不依赖当前时间。

## 为什么这么写
窄表便于动态增加指标并按指标聚合，宽表减少行数且列式读取方便。分区演示用日期 RANGE 分区和单日等值条件，使计划只保留对应子表。

## 易错点
- 宽表行数少不等于字节数一定更小，NULL 比例、索引和指标数量都会改变结果。
- 若查询没有分区键过滤，或把分区键包进不匹配的表达式，计划可能扫描多个分区。

## 依赖服务
`postgres`
