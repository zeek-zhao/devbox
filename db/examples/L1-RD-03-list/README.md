# L1-RD-03-list · 链表

## 考点
- LPUSH 多值插入的顺序与 RPUSH 追加共同形成有序列表。
- LPOP 移除头元素，LINSERT 在指定值前插入，LTRIM 原地保留指定区间。
- 输出裁剪后的完整列表和 LLEN。

## 为什么这么写
列表元素均为固定字符串，操作后通过 LRANGE 读取；结果体现列表的端点语义和索引为闭区间的裁剪行为。

## 易错点
- LPUSH 同时传多个值时，最终顺序与参数直觉相反。
- LTRIM 的结束下标包含在保留区间中。
- LINSERT 的 pivot 必须存在，否则列表不会按预期增长。
